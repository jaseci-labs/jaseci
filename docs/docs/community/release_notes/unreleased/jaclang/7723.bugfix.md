- **Fix: `jac install --shadcn` follows the project's layout instead of forcing `components/ui/`**: the installer hardcoded `components/ui/` for writes and listings and `lib/utils.jac` for `cn()`, so a project that kept its primitives anywhere else got a second `components/ui/` created beside the real one, its primitives silently split across two directories, and `jac install --shadcn` in list/remove mode failed with "No components/ui directory found". It now resolves the target: an explicit `[jac-shadcn] components_dir` / `utils_path` wins, otherwise it uses `components/ui/` when present and otherwise discovers an existing `*/ui` directory holding `.jac` files. Each installed primitive's `cn` import is rewritten to the correct relative depth for wherever the `utils` module actually lives (`...shared.utils` for `shared/ui/`, and byte-identical `...lib.utils` for the default layout). Projects on the default layout are unaffected.
