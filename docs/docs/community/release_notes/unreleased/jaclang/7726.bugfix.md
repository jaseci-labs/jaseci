- **Fix: sealed builds demoted live cross-module `na_stdlib` calls, failing `jac check` on `urllib/request.na.jac` (#7726)**: the conservative fallback added in #7672 marked every archetype method of a jaclang-internal import as having no native lowering whenever that module carried no recorded `native_layout`, and the companion `_forward_declare_method` guard then refused to prototype them. Because the rule is gated on running from a sealed jaclang image, it fired in CI while staying inert in a local dev checkout. It was too broad for a `.na.jac` import: `na_stdlib` modules are lowered from source in the same pass and forward-declared moments later, so every cross-module call into `socket` and `SSLSocket` from `urllib/request.na.jac` became a hard `E5092`. `.na.jac` imports are now excluded from the blanket skip, while non-native jaclang-internal imports keep the conservative treatment, so sealed builds still neither bind dead native bodies nor demote live cross-module calls.
