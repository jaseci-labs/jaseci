- **Feat(c2jac): lift forward `goto`-error ladders to `try`/`finally`**: The C-to-Jac lifter previously quarantined (Tier-B) any function containing a `goto`/label, stubbing the whole body at call time. It now recognizes CPython's canonical forward error ladder (exactly one tail label, one or more `goto`s all targeting it, and no `goto`s in the cleanup region) and lifts it to `try { guards then raise } finally { cleanup }`, promoting those functions to a faithful Tier-A lift. A guarded `if (cond) goto L;` becomes `if cond { raise Exception(); }`; a trailing `return` in the cleanup moves past the `finally` (success path); and cleanup that fully elides (e.g. `free`/`realloc` dropped by FREE_ELIDE) drops the empty `finally` wrapper. Anything not matching the strict shape bails to the existing quarantine path, so recognition is all-or-nothing.
