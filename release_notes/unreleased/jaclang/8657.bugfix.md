- **Scale: a request whose asserted user root cannot be bound is rejected with a 401**: `request_context_middleware` used to catch the bind failure, log "using system root", and continue the request on the system root, which bypasses the owner check and disables the traversal ACL gate; only a redundant downstream bind (a 500 with a traceback) prevented a fail-open at the tenant boundary. An asserted caller identity that cannot be resolved (malformed root id, or a root that no longer exists in the anchor store) now rejects the request with a structured 401 `UNAUTHORIZED` response; the exception detail stays in the server log. Requests that assert no identity are unchanged. Fixes #8348.
