- **Invariant prompt hoisting (opt-in)**: `[byllm.optimizations] invariant_prompt_hoisting = true` (or `BYLLM_INVARIANT_HOISTING=1`) splits each `by llm()` prompt into a byte-stable invariant prefix and a variant suffix. Everything the compiler already knows (description, parameter names/types/semstrings, `self` semstring, return type, schema hint, a literal `tools=[...]` list) moves into a second system message rendered once per ability, so provider prefix caching covers the function-specific invariants across calls instead of only across ReAct iterations. `visit ... by llm()` routing gets the same split when every candidate archetype is one the compiler registered. A call that passes a `system_prompt` the compiler cannot prove constant keeps the old layout, since that text would sit in front of the contract block and break the byte-stable prefix. Off by default, and byte-identical to the previous output when off.
- **Per-call usage log**: setting `BYLLM_USAGE_LOG` to a file path appends one JSON line per completion call with `scope`, `prompt_tokens`, `cache_read_input_tokens`, `cache_creation_input_tokens`, `invariant_tokens`, `cost`, and `latency_ms`.
- **Per-model prompt-caching override**: a model can turn Anthropic prompt caching on or off for itself with `Model(..., config={"prompt_caching": False})` (a bool, or a `{"enabled": bool}` dict), overriding the global `[byllm.prompt_caching]` toml default. The Claude-only model gate still applies.
