- **The client bundle owns `/docs` at the microservice gateway, and read-tier retries are visible** (#8742): the gateway classified `/docs` with the wellknown machine endpoints, so a fleet shipping a client bundle could serve Swagger (or a headless service's Swagger, through the app-route probe) where the app's docs reader belongs, and a non-GET `/docs` still answered with the API docs page. The route classifier now files `/docs` as a client page whenever a client bundle ships: `GET` serves the SPA, other methods get a 404, Swagger is unreachable there, and headless fleets keep the API docs page unchanged. Separately, every request re-run at SERIALIZABLE after a read-tier unit wrote now logs at info on `jaclang.serve` with the unit key and increments `{namespace}_read_tier_retries_total{unit}` when Prometheus metrics are enabled, so per-replica re-learning after a rolling deploy is observable; the writer record is per process, so each replica re-learns its writing units once per `JAC_DB_RO_WRITER_TTL_S` window (all at once on a rolling deploy), and a higher TTL trades fewer re-learn passes for a transiently demoted read path staying at SERIALIZABLE longer. That knob and the connection-pool knobs are documented under Persistence.
