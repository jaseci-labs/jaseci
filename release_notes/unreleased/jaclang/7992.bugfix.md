- **Fix: JIR MTIR cache duplication and same-stem collision**: per-module `.jir` files now store only that module's `SEC_MTIR` entries instead of pickling the entire program-wide `mtir_map`, eliminating multi-GB disk and RAM bloat on projects with large `by llm(...)` surfaces. MTIR is now associated with its owning module at generation time via `JacProgram.mtir_by_module` (keyed by a dirname+stem identity), so the cache slice is an O(1) lookup and same-stem modules in different directories (e.g. `pkg_a/utils.jac` and `pkg_b/utils.jac`) no longer cross-contaminate each other's caches.
