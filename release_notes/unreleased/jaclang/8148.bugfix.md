- **Native: an enum member written as a constant expression had no value, and `__class__.__name__` refused a receiver whose static type named no class** (issue #8148): two unrelated backend gaps kept `NameAtom.sem_token` out of the sealed native parser, where it shipped as an `abort()` stub waived four times over (the base plus its re-emission on `Name`, `SpecialVarRef` and `BuiltinType`). **First**, an enum member's value was derived from the *shape* of its initialiser's AST node -- `Int`/`String`/`MultiString` and nothing else -- so `1 << n`, the idiomatic spelling of a flag member and the one every member of `JacSemTokenModifier` uses, produced no value at all. Three sites carried the same test and each failed differently: `LayoutPass._build_enum_layouts` fell back to `0`/`""` for a Jac `enum`, so `enum Shift: int { A = 1 << 0, B = 1 << 2, C = 5 }` lowered natively to `0, 0, 5` against CPython's `1, 4, 5` -- no error, no warning, no demotion, and `A` and `B` colliding with each other and with any literal `0` member; `class_form_enum_literal` returned nothing for a class-form enum (`class M(IntFlag)`), which drops the member from the layout entirely and refuses the read with `E5092`; and `create_enum_member_info` left `EnumMemberInfo.literal_value` unset, so the implicit-value chain did not advance past such a member. All three now fold the initialiser through the existing `fold_const`, and the classification the node-kind test encoded is preserved (a `bool` initialiser is still not an int-valued member, a non-constant initialiser still has no value). **Second**, `__class__.__name__` resolved its receiver statically, so the answer existed only where the static type already named one archetype -- freeze its name, or walk the class-name constant in vtable slot 0. `sem_token` reads `type(self.type).__name__` where `self.type` is `TypeBase | None`, a class reached through a typing-only import, which lowers to an opaque object pointer with no struct behind it and no known vtable, exactly like a type-erased generic slot. The read now falls back to the class-name stamp every construction path writes into the rc header, the same authority `runtime_struct_name` re-keys marshalled views with (#8093), behind that function's own header-validity test, so an unstamped or foreign pointer answers with the empty string rather than with whatever precedes it; a null receiver answers `NoneType`, matching CPython. An option receiver is unwrapped first, with the absent arm carried through as null instead of dereferencing a dead payload slot, and a receiver that is not a pointer at all (a boxed `any`) is still refused rather than guessed at. The same change removes an abort: the vtable walk used to be reached whenever the static type named a vtabled class even when the receiver had not lowered to a pointer to it, and `gep` on an `i64` or on a JacOpt value raised out of the emitter and took the whole compile with it. `unitree`'s native census drops from 28 seams to 24, retiring all four `sem_token` waivers.
