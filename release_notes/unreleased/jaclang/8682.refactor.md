- **`JacProgram` splits into lifetime organs and diagnostics become values** (#8682): the program facade now composes `ModuleHub`, `DepGraph`, `DiagLedger`, `BuildScratch`, and `AnalysisCaches` (`compiler/driver/progstate.jac`), with `errors_had`/`warnings_had`/`mod`/`mtir_map` kept as in-place aliases so the read surface is unchanged; former private paths route through the organs (`prog._compile_options` is now `prog.options`, `_na_dep_units` is `prog.scratch.na_dep_units`, and so on). `Alert.loc` is a value-typed `Span` carrying a captured source window -- a diagnostic no longer holds tokens or a `Source`, so retaining alerts cannot pin a module, and dropping a module's alerts filters precomputed owner keys. The pass rim's construction metaclass is gone: the sealed-tier tripwire rides `PassRim.__new__`, and the program handle is a declared field on `HOST_PASS`-tagged passes that `run_pass` feeds only to them, so the sealable base chain never names a host type.
