- **Fix: a filter applied after a typed edge reference no longer returns every node**: `[root-->[?:Session]][?id == sid]` silently dropped both the type filter and the condition, returning every node connected to the root rather than the one that matched. Written this way, a lookup meant to fetch a single record could return every record it was meant to filter out. Such queries now return the same result as `[root-->[?:Session, id == sid]]` and `[root-->][?:Session][?id == sid]`, which were already correct. Only projects with a `jac.toml` were affected, since the topology index is enabled by default for them.
