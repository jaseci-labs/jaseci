- **Fix: an imported `.d.ts` type reports itself as a type**: A binding imported from a TypeScript declaration file answered `kind: type` and `category: variable` at the same time, so hover and outline in the editor labelled an imported `interface` or `type` alias a variable. The category now follows the kind: a type-only import is a type, while a `class`, `const` or `function` import stays a variable.
- **Fix: the hot reloader reports a syntax error the same way on both compile paths**: One path printed `Syntax error in <file>:<line>: ...` and the other `Syntax error in <file> at line <line>: ...` for the same failure. Both now use the `<file>:<line>` form, which matches every other location the dev loop prints.
