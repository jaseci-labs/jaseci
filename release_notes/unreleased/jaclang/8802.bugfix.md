- **Fix: the macOS x86_64 binary segfaulted the moment it started**: `jac --version` died with `Segmentation fault: 11` on Intel Macs, so 0.37.0 and 0.37.1 shipped no `macos-x86_64` asset. The launcher's Mach-O image marked itself position-independent while its read-only `__TEXT` held hard-coded addresses that nothing could rebase, so the first run at a slid load address dereferenced stale pointers. The Mach-O linker now sets that flag from what it actually emitted, and refuses outright to link an arm64 image that cannot move. Apple Silicon and Linux binaries are unchanged.
