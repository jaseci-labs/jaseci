- **JSX statement slots keep stable child positions**: an `if`/`else` or `for` used as a JSX child pushed its output into the slot's shared accumulator, so a false branch or a changed loop length shifted every later sibling's index and React remounted them, discarding their state; the slot fragment also nested the accumulator one level too deep, which React reported as a spurious "unique key prop" warning on non-repeating content. Each slot statement now contributes exactly one child: conditionals lower to a single conditional expression, loops lower to a single nested array where the author's per-item keys still apply, and the fragment receives the accumulator's contents as positional children.
