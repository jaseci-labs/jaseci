- **JSX statement slots keep stable child positions**: an `if`/`else` or `for` used as a JSX child could move its siblings whenever a branch was skipped or a loop's length changed, so React rebuilt those siblings and discarded their state, clearing typed input and resetting scroll or focus. The same lowering also produced a spurious "unique key prop" warning in development on content that never repeats. Each statement in a slot now holds a fixed child position, so siblings survive across renders and the warning is gone.
