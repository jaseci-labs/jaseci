- **Fix: a native demotion can no longer ship inside a sealed artifact as an abort stub**: A method the native backend cannot lower is demoted to its Python implementation, which in-process costs only speed. A sealed AOT artifact has no Python left to fall back to, so the same demotion is emitted as an `abort()` stub and the first call kills the process with no diagnostic -- the mechanism behind the sealed native parser artifact's unexplained segfaults. `seal_native_artifacts` now wraps each module's compile in the existing native census and refuses to seal when anything in the sealed closure demoted, naming every offending method with the reason it could not lower. A knowingly-unreachable demotion is waived only by naming it as `<module>::<Type>.<method>` in the new `NATIVE_SEAL_DEMOTION_WAIVERS` table beside `NATIVE_SEAL_MODULES` (the module half is required, so a waiver cannot silence a same-named method demoting elsewhere in the closure); each waived method is announced on every seal and a waiver that matches no real demotion is reported as stale. The verdict is made independent of build-cache warmth: the seal compiles its closure with the native IR cache disabled (a warm `.ir_cache` entry for a transitive native import skips codegen for that module, so its demotions would be recorded nowhere), it independently scans the LLVM IR it is about to link for the demotion stub signature and refuses any it finds regardless of what the census saw, and any refusal purges the native IR cache entries for that closure so a failed seal leaves no state a later build could inherit. Before an artifact is written into `MANIFEST.json` it must also pass a load canary: the seal `dlopen`s the freshly linked library, confirms every export the layout advertises really resolves, runs `__jac_shared_init`, and calls a known-good runtime export, deleting the artifact and failing the seal otherwise. `JAC_NA_DEBUG` is formalized as the diagnostic gate that explains all of this: read once at the options boundary into `CompileOptions.na_debug` (outside the codegen fingerprint, so no compiler pass reads the environment), it prints `NA_DEBUG demote <method>` with every diagnostic behind the demotion, `NA_DEBUG raise <method>` with a traceback when the emitter raised, forces the native-seam warning on regardless of `[check] warn_native_seams`, and surfaces the traceback behind a failed canary. The production seal is unaffected: the bootstrap lexer lowers with zero demotions and its artifact is byte-identical.
- **Fix: the merged wasm libc bitcode is written atomically**: `wasm_build._load_libc_module` cached its merged libc as `_merged.bc` with a plain truncating write while concurrent readers were admitted by nothing but an mtime comparison. Under `pytest-xdist` one worker could truncate the file and begin writing while another read it, yielding `LLVM bitcode parsing error: file too small to contain bitcode header` from an otherwise unrelated wasm test. The merged file is rebuilt on every run, so the window was open every time and the failure looked like a flake. It is now written to a sibling temp file and `os.replace`d into place, so a reader observes either the previous complete file or the new one. Separately, `clone_for_native_import` now carries `no_ir_cache`, so a compile that deliberately bypasses the native IR cache bypasses it for nested native imports too instead of only one level deep.
