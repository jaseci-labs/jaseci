- **`comptime`: values the compiler computes, in the Mojo and Zig family**: Jac gains value-level compile-time evaluation. A `comptime` binding (`comptime WIDTH: int = 4;`) is evaluated while the module compiles and folded into the program; `comptime if` selects a branch and drops the other before codegen; `comptime for` runs its body once per element of a compile-time collection; `comptime assert` fails the build with `E0109` instead of a runtime exception; `comptime def` declares a function that only exists at compile time; `comptime import` pulls names in for compile-time use only; and a `comptime` parameter (`def repeat(comptime n: int, msg: str)`) makes every call site pass a compile-time-known argument, which the native backend specializes into one function per distinct value. Anything a `comptime` site cannot settle reports `E0033` ("not known at compile time") with the reason, and a compile-time evaluation that raises reports `E0108`. The evaluator interprets a fuel-limited subset of Jac (literals, containers, arithmetic, comparisons, comprehensions, `obj` construction, method calls, `try`/`except`) and reads program facts through `jaclang.comptime` (`typeof`, `fields`, `field`, `set_field`, `has_field`, `members`, `semstr`, `name`, `module_of`, `is_subtype`, `codespace`, `target`). On the Python and client tiers comptime constructs erase to their runtime twins with the computed values inlined; on the native tier they lower to constants, unrolled bodies, and specialized functions. A `ComptimeResolvePass` in the IR-gen schedule settles every comptime site even when type checking is off, so imports and `jac run` see the same folded program that `jac check` does.
- **The CLI manifest is a `comptime` value**: every command declares a `comptime SPEC_<NAME>: CommandSpec` next to its `def`, and `jaclang/cli/manifest.jac` folds those specs into one `ROUTES` table at compile time with `comptime import` and a `comptime def` that stamps each handler's module through `module_of`. The generated route table, the `@registry.command` decorator, `jac tool gen-cli-manifest`, the manifest parity test, and the client-target choice sync are gone; help, completions, MCP tool listings, and dispatch all read the folded table. `jac --help` no longer imports a single command module to render.
- **`fields()`-driven record conversions**: `TriggerSpec`, the desktop `WindowConfig`/`DispatchConfig`, the scale `BaseConfig`, and the auth request models derive their `from_dict`/`to_dict` bodies from `comptime for f in fields(T)` instead of hand-listing every field, so a new `has` line cannot drift out of the converters. The chess example computes its piece tables under `comptime assert` coverage of `members(PieceKind)`, and the day-planner copies an `Ingredient` into a `ShoppingItem` field by field with `comptime for`.
