Queries are data: edge-reference expressions now compile to a closed, typed GraphQuery IR (types as classes, predicates as `QPred(field, op, value)` data, comparators evaluated once) resolved by a planner in id space — the storage engine answers type-narrowed hop rows and predicate filters inside its own indexes (`graph_edges`/`graph_types` in SQLite, edge docs + ancestry collection in Mongo), the request overlay guarantees read-your-writes, and objects deserialize exactly once per query, for winners. Every filter spelling (`[-->[?:T, p]]`, `[-->[?:T]][?p]`, `[-->][?:T][?p]`) is now equivalent and correct; filters outside the closed sublanguage are a compile error (E5094) with a fix-it instead of a silent drop. BREAKING: `[?...]` predicates are pure (evaluated zero-or-more times; comparators once); the callable-filter `refs()`/`OPath` API, the `TopologyIndex` blob, `topo_utils`, and the `[run] topology_index` knob are removed; existing databases auto-reindex on first open.
