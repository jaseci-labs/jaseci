- **Fix: `{ default as X }` npm imports were always typed Unknown**: `default` parses as a keyword token rather than a name, and the type evaluator bailed out before the npm `.d.ts` lookup ever ran - so every use of a default import (e.g. `import from "mermaid" { default as mermaid }`) emitted a spurious W1051 while named imports from the same package typed fine. Default imports now resolve through the same declaration pipeline as named items: packages shipping an `export default` declaration get its real type (misuse is a genuine type error), and undeclared packages fall back to gradual foreign any with a single W1102 at the import line.
