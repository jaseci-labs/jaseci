- **PyObject-unitree: natively parsed trees are Python objects (#8789)**: when a natively compiled frontend is armed via `JAC_FRONTEND_LIB`, unitree nodes built by the native parser carry CPython object headers, so passes read them as ordinary Python objects: scalar fields through `tp_members` descriptors at interpreter speed, adjacency through one native call per query, with no proxies, handles, or per-node conversion. The installer builds one CPython type per unitree class over the native struct layout, mirrors the jac class hierarchy so `isinstance` works throughout, and rebinds the source modules' names at import time. `jac check` runs green end to end on the native frontend (chess example included), with parsing measured ~32x faster than the bytecode path. Off by default; behavior without the env var is unchanged.
