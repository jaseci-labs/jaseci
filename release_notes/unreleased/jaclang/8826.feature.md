- **byLLM: a deterministic cache-break signal on every Anthropic call**: `#8386` fixed the one code path that shrank `mt_run.tools` mid-turn and broke Anthropic's prompt-cache prefix, but byLLM still had no way to tell a caller a break had happened -- only inference from raw `cache_read_input_tokens`/`cache_creation_input_tokens` counts across calls, which false-positives on a legitimate large conversation write (e.g. a big batch of tool results). byLLM builds the `tools` array and system message Anthropic's cache breakpoints sit on, so it now fingerprints both before marking them for caching, compares against the previous call in the same turn, and attaches `cache_break_expected`/`cache_break_reason` (`"tools_changed"` or `"system_changed"`) to that call's usage dict -- the same `CompletionResult.usage`/`usage` `StreamEvent` `per_call` channel existing cost and telemetry consumers already read.
