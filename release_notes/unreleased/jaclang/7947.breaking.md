Postgres-native persistence replaces the tiered memory stack (#7945). The
database transaction is now the single source of truth: each request runs in
one SERIALIZABLE transaction with automatic re-run on conflict, so uncommitted
attaches, detaches, and destroys are always visible to same-request traversals
(fixes the #7937 defect class structurally). Graph queries compile to single
SQL statements. Zero-config runs use an embedded Postgres (fetched on first
use); scale deployments provision postgres:19, run the jac image itself via
`jac db serve`, or point JAC_DB_URL at any managed Postgres. Redis, MongoDB,
and Firestore backends are removed; websocket backplane, event streams, shared
state, auth tokens, scheduler jobs, and webhook keys all ride the same
database. 0.35.x session data is not migrated (clean break).
