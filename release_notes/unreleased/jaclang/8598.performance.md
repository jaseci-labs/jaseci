- **A node's stored size no longer grows with its degree**: `Session._serialize` wrote the full adjacency list into every node's `props` blob, so a node's row grew ~40 bytes per edge -- 782 kB measured at 20k edges, and past Postgres's 1 GB per-field ceiling somewhere before 10M. The list was stored twice over, since `load_full` already derives adjacency from the edge rows' own `src`/`dst` and ignores the copy in props. The persistence boundary now drops `edges` before storing, matching what `_persist_hash` already did, so node rows are O(1) in degree. Adjacency, traversal, and the API wire format are unchanged.
