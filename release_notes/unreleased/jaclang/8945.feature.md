- **Client build: client output is cached beside the bytecode**: A module's client JS, manifest, native imports, and source map are stored in its JIR module cache and served on a warm `jac run` without recompiling. Editing the module, or any file it imports, invalidates the entry.
- **`jac run`: the initial client compile reports progress**: One status line names the module being compiled as the compiler picks it up, and the completion line reports how many modules compiled or that all were served from the cache, with the elapsed time.
