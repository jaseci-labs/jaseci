- **`W5096` names a traversal that stays in object space**: The counterpart to `E5094`. A predicate or ordering term inside a reference resolves in the query; a sort that cannot fold does not, and the cost is O(degree) either way it is written. The warning fires where the author asked for something foldable and it could not be -- a `sorted()` key that computes rather than names a field, and an in-place `.sort()` over a name bound from a traversal, which cannot fold because it mutates a binding. It is a warning, not an error: computing a sort key is a legitimate thing to want, it just cannot be free, and the language should say so at the site rather than let it be discovered in production.
