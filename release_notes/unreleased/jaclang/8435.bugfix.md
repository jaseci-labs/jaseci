A finished compile now releases what it no longer owns: boundary facts carry the extracted decls instead of the imported module's whole tree, the native verdict memo drops its LLVM state when the outermost compile returns, and the type evaluator's id()-keyed flow caches are cleared at the same seam. Hub lookups normalize through `JacProgram.hub_key`, so a symlinked root no longer defeats the module hub and forks a private parse per importer.
