- **Fix: `jac test` no longer grows memory with the number of test files**: A finished test file kept its module, and everything defined in it, alive for the rest of the run, so a long suite climbed steadily in memory and could exhaust a machine before finishing. Each file is now released as the runner moves on, and the tables that track archetypes no longer keep a class alive after its module is gone. On a 40-file measurement peak memory fell from 521 MB to 188 MB.
