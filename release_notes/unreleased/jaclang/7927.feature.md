- **Client capability check (E5096)**: constructs with no ES lowering (`yield` expressions, `flow`/`wait` concurrency) in client-placed elements previously vanished from the bundle silently; they are now diagnosed both in the typecheck schedule and as a codegen-time backstop, complementing the emission-time E5017 statement guard.
- **Evidence-based PERSIST for graph archetypes**: node/edge/walker archetypes anchored server-side unconditionally, which made rootless in-memory object models (a block graph, a scene graph) unreachable in the client bundle even though the client OSP kernel executes them fully in-browser. An archetype now anchors (and refuses client pulls) only when its defining module actually touches `root`; persisting programs keep exactly the old placement. Statically-known native rejects also no longer propose native placement, eliminating guaranteed-demotion attempts and their per-compile notes.
