- **Compiler: the graph-shaped compiler (#8744)**: syntax nodes are immutable object-spatial nodes, tree structure and semantic relations are typed edges, the type system is nodes and edges in the same graph, and every pass is a walker. Node fields that passes used to assign (`kid`, `body`, `type`, `sym`, ...) are read through generated accessors over edges. The jac0 seed tier now lowers the object-spatial subset (`node`/`edge`/`walker`, connect, edge references, `spawn`, `visit`, abilities) so the seed compiler is graph-shaped too. Also fixes the bytecode kernel's quadratic connect (#8743, hash only).
- **Runtime: subtree-fenced `visit:0:`**: front-splicing visits (`visit:0: targets;`) now give walkers true depth-first traversal with enter/exit abilities bracketing each subtree (a node's exit fires when its subtree completes, not when the queue drains). Plain `visit` keeps the legacy queue semantics. The kernel also gained `osp_skip_rest` (suppress the current node's remaining abilities), per-walker `__jac_post_entry__`/`__jac_post_exit__` callbacks, and a typed-dispatch match cache.
- **Compiler: pass hooks are typed OSP abilities**: the `enter_<node>`/`exit_<node>` visitor surface (`accept_enter`/`accept_exit` double dispatch, ~460 generated stubs) is deleted. Passes declare `can enter_x with IfStmt entry { ... }` and the walker kernel dispatches them by trigger type; ability triggers use `isinstance` semantics, so hooks on types with node subclasses carry explicit exact-type guards where the old exact-match behaviour matters. Third-party passes using `def enter_<node>` methods no longer dispatch and must convert to abilities. `jac gen-uni-dispatch` is removed.
- **Compiler: `JAC_COMPILER_DIGEST_PIN`**: a developer knob that freezes the compiler-tree digest folded into every JIR's environment key, so an edit to the compiler recompiles only the modules whose own source changed. Unset, behaviour is unchanged.
