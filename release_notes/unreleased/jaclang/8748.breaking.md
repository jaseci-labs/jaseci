- **Compiler: the graph-shaped compiler (#8744)**: syntax nodes are immutable object-spatial nodes, tree structure and semantic relations are typed edges, the type system is nodes and edges in the same graph, and every pass is a walker. `UniPass` is retired; node fields that passes used to assign (`kid`, `body`, `type`, `sym`, ...) are read through generated accessors over edges. The jac0 seed tier now lowers the object-spatial subset (`node`/`edge`/`walker`, connect, edge references, `spawn`, `visit`, abilities) so the seed compiler is graph-shaped too. Also fixes the bytecode kernel's quadratic connect (#8743, hash only).
- **Compiler: `JAC_COMPILER_DIGEST_PIN`**: a developer knob that freezes the compiler-tree digest folded into every JIR's environment key, so an edit to the compiler recompiles only the modules whose own source changed. Unset, behaviour is unchanged.
