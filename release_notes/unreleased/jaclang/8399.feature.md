- **Type checking joins the critical path**: the analysis suite (type
  inference, ownership checking, and their companions) now runs on every
  compile rather than only when a tool asked for it, so a type error
  surfaces the first time a module builds instead of the first time an
  editor opens it. The native backend rides the same rails: annotations
  in imported modules lower from one shared resolution (structural
  mirrors for containers, unions, callables, and enums), which removes a
  class of cross-module ABI corruptions in sealed native kits.
