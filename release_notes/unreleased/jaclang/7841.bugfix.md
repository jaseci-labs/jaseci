- **Fix: goto-definition broken for string-form imports**: F12 on an item imported from a client npm package (e.g. `ArrowRight01Icon` from `"@hugeicons/core-free-icons"`) silently jumped to the token itself, and F12 anywhere inside a string module path (`"@jac/runtime"`, `"@hugeicons/core-free-icons"`) returned nothing - the LSP never consulted the npm resolvers the type checker already uses. Items imported from npm packages now land on their exact declaration line inside the package's `.d.ts` (falling back to the declarations or entry file at the top), string module paths open the resolved module the same way dotted paths do, and a symbol whose only known definition is the queried token itself now reports "no definition" instead of a fake self-jump.
