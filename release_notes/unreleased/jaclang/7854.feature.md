- **Smaller, faster native binaries by default**: the reference-counting debug and leak-trace instrumentation is now compiled in only when the `JAC_RC_DEBUG_CODEGEN` build flag is set. A normal native build no longer carries the trace format strings or the extra per-operation bookkeeping, producing a noticeably smaller binary with less allocation/retain/release overhead. Set the flag to get the full runtime-toggleable RC trace back.
