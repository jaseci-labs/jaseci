Native: a `(T | None)` field on a generic archetype no longer drops the value it is constructed with. The slot was classified as a foreign optional, so the constructor skipped it and its declared default was discarded, and it read back as `None` however it had been built while a later assignment to the same field worked. An unsolved type parameter erases to the same pointer a bare `T` field uses, so the option now lowers through that erasure and takes part in construction and defaults. Instantiating a generic archetype at a scalar type argument, where the erasure is unsound because a pointer slot cannot carry an unboxed value and its null aliases a zero payload, is refused with `E5092` naming the archetype, the slot and the type argument instead of segfaulting or answering `None`.
