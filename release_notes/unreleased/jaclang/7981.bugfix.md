- **Fix: Native container element types come from the checker**: The native backend re-derived list element storage instead of consuming the checker's inference. An untyped list of enum members fell back to tagged storage and produced invalid IR when compared against an enum constant, and a `list[float]` whose first element was an int literal silently built i64 storage and truncated every element. Element types now lower through the checker's answer, and a comparison between a tagged element and an unboxed peer either boxes both sides or reports E5090 instead of emitting a mismatched comparison.
