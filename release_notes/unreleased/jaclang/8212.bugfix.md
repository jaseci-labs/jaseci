Cleared a batch of native placement and lowering gaps: `abc`'s `ABC` and `abstractmethod` are erased as the compile-time markers they are instead of demoting every module whose import closure reaches them; a `TypeVar` / `ParamSpec` / `TypeVarTuple` glob is read as a compile-time declaration rather than a runtime value; an empty `set()` or `list()` in a ternary arm takes its element flavor from the other arm; a `list[jacval]` reaching a `list[ptr]` slot is rebuilt element by element instead of refused; `id()` answers for float values as well as pointers and ints; and `dict.keys()` / `dict.values()` build their result under the canonical pointer layout instead of crashing the emitter.
