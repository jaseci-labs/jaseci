- **OSP single source of truth (edge layer)**: edge semantics now live once in `jac0core` (`osp_graph.jac` alongside the `osp_kernel.jac` walk engine) and all three backends lower `++>`, `[... -->]`, and `del -->` to the same store functions, with per-host identity drivers (a JS object/handle table on the client; a UUID-keyed, per-context driver over anchors on the server, where anchors remain the persistence record and the query planner's SQLite/projection arms are untouched). The client's hand-written edge shim is deleted; bare edge ops and walker traversal finally share one substrate in the browser. New central `osp_disconn_between` and `osp_edge_peer` back disconnect-between and predicate hops everywhere.
- **Four silent cross-backend divergences fixed by the same change**: client edge refs hardcoded `here` as the traversal origin (explicit origins silently became `undefined`); server `disconnect` ignored `is_undirected`; native dropped edge-attribute predicates on node-returning hops and on edges-only hops. New equivalence fixtures (`osp_plain_fn_ops`, `osp_interop`, `osp_disconn_between`) run with hard `require` gates so the next divergence fails CI instead of shipping.
- **E5097**: an expression the client pathway cannot lower is now a loud error at the consumption seam instead of silently becoming `undefined` in the bundle.
