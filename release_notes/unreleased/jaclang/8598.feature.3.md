- **Traversals can carry an ordering and a bound**: `GraphQuery` gains `order` (a list of `QOrder(field, desc, on_edge)`), `limit` and `offset`, which compile to `ORDER BY` and `LIMIT`/`OFFSET` instead of being applied to a fully materialised result. Ordering names a promoted column when one is declared and the raw jsonb path otherwise, and replaces the edge-sequence default only when asked for; origin ordering stays outermost so multi-origin results still group. The bound is pushed only when the request is not ACL-gated: dropping rows in SQL before the ACL filter would change `[:n]` from "n you may see" to "up to n, some of which then vanish", so a gated request applies the bound in object space instead.
