- **Fix: a test file's project config no longer leaks into the next file**: `JacRuntime.reset_process_state` now also clears the `jaclang.project.config` globals. A serving-test harness that pinned a config via `set_config` left it explicit for the whole worker process, so a later test file's out-of-project compiles (dynamic modules in the test base) inherited that project's lint rules and could fail on them -- the order-dependent `dynamic archetype creation` failure in the runtime lane. A regression test pins the reset.
