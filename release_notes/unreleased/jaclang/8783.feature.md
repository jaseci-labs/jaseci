- **Feature: every dev-loop and client error names a Jac location**: A blank page in `jac run --dev` used to leave only a Vite module id and an empty `file`. The dev loop now resolves every failure it can see -- a Jac compile error, a Vite resolve failure, a browser module-link error, an uncaught exception with a stack -- back to a `.jac` file:line:column (or a `jac.toml` `[dependencies.npm]` line), classifies it under the new `E7001`-`E7006` codes, and renders it with the same renderer `jac check` uses. Client source maps are now segment-level (generated column plus a `names` array), so an import specifier or a stack frame resolves to an exact column. When nothing on disk claims a location, the diagnostic still names the best-known Jac owner and carries an explicit `unmapped_reason` -- the `file` field is never silently empty.
