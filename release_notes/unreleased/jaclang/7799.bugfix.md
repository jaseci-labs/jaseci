- **Fix: cold builds no longer misclassify client components as native wasm targets**: the cl→na edge classifier walked a recursive "native anchor" scan through whatever modules happened to be in the compile hub, so a client JSX component whose transitive imports reached a native module could be emitted as a `__na_bind` wasm stub on the first cold build (with a failed na→wasm attempt on the JSX module), then compile correctly on later passes -- and the vite bundle, whose staleness signature only hashed source mtimes, kept serving the broken first build until `dist/` was deleted. The classifier now demands the import target's own decided placement (materializing it through the placement stage when needed) and accepts only in-body native evidence (ownership annotations, clib declarations); hub path lookups realpath-normalize so symlinked paths cannot alter classification; and the bundle staleness signature now digests the emitted compiled tree's content, so any emission change rebuilds the bundle.
