- The type checker learns three narrowing rules. User-defined predicates typed `TypeIs[T]` (PEP 742) or `TypeGuard[T]` (PEP 647) now narrow at their call sites: `TypeIs` on both edges, positive to `T` and negative by subtracting it, `TypeGuard` on the positive edge only, where it replaces the declared type outright. `isinstance` narrowing keeps the declared type as a constraint instead of discarding it, so a guard against a class unrelated to a declared union member yields a synthesized `<subclass of Member and Filter>` carrying both sides' members rather than the filter class alone. And a short-circuit chain now narrows only on the edges it licenses: the false edge of `A and B` says nothing about `A` on its own, so `if isinstance(x, Foo) and x.bar { } else { }` no longer excludes `Foo` from the else branch, and the mirror rule holds for a disjunction's true edge.
