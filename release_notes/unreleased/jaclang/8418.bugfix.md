- **`jac fmt` no longer deletes the `awaiting` clause of a `try` statement**: `DocIRGenPass` had no `awaiting_clause` handler, and because `CodeGenTarget.doc_ir` lazily materializes an empty `Text` for any node a pass never assigns, the clause rendered as the empty string and was written back to disk gone, with no diagnostic. The clause now renders like its `except` and `finally` siblings, and `DocIRGenPass` gained the `default_exit` fallback that `UnparsePass` already had, so an unhandled node degrades to a plain rendering of its kids instead of silently dropping its source. A test pairs the two tool passes so a node kind that `NormalizePass` normalizes but `DocIRGenPass` cannot render fails at the moment it is added.
