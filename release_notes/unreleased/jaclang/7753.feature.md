- **Full documentation bundled with the binary**: The entire documentation set now ships inside the jaclang package and is served offline by `jac guide` -- namespaced doc sets (`reference`, `quick-guide`, `build`, `tutorials`, `internals`, `community`), unified name resolution, grep-style `--search` with line-accurate hits, a `--json` index, and `jac://docs/*` MCP resources. The docs corpus at `jac/jaclang/cli/docs/` (with `nav.json` as the navigation manifest) is the single source of truth for the website, the CLI, and MCP; the mkdocs site and its deploy pipeline are retired, and release-note fragments now live at `release_notes/unreleased/` in the repo.
