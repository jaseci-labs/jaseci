- The native frontend now materializes: the kernel lib (libjac_compiler, built by mkpayload from jc_unit.jac) parses and weaves annexes natively, then hands Python the ordinary unitree in a single call and drops its graph state. The PyObject-bridge design of #8817 is superseded; compiler passes run on plain Python objects at full speed, and JAC_COMPILER_LIB=off selects the store parser explicitly.
- Worker pools (`jac test`, `jac check`, `jac fmt`, precompile) now dispatch within the machine's memory rather than only within their slot count: before handing out an item the pool checks that the largest single-item growth seen so far is still available, parks a worker otherwise, and retires a parked worker that already holds more than its share of the start budget. One item is always in flight, so a starved runner slows down instead of losing the agent (and every log line) to the OOM killer. Parking and retirement show up in the `JAC_TEST_RSS_LOG=1` footprint log.
