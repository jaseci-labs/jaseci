The native frontend now materializes: the kernel lib (libjac_compiler, built by mkpayload from jc_unit.jac) parses and weaves annexes natively, then hands Python the ordinary unitree in a single call and drops its graph state. The PyObject-bridge design of #8817 is superseded; compiler passes run on plain Python objects at full speed, and JAC_COMPILER_LIB=off selects the store parser explicitly.
