- The native frontend now materializes: the kernel lib (libjac_compiler, built by mkpayload from jc_unit.jac) parses and weaves annexes natively inside one region, hands Python the ordinary unitree in a single call, and drops the whole parse with that region. The PyObject-bridge design of #8817 is superseded; compiler passes run on plain Python objects at full speed, and JAC_COMPILER_LIB=off selects the store parser explicitly.
- Native regions gain a dynamic extent inside the compiler kernel's own modules: an archetype constructed by any callee while an `in <region> {}` block is active lands in that region, so a bounded phase such as a parse is reclaimed wholesale at the block's end regardless of reference cycles.
- Native shared objects now carry a local `.symtab`, so valgrind, gdb and perf name every function inside a kernel or plugin library (the kit's strip step removes it from shipped artifacts). Bytecode modules are keyed on the compile options that affect analysis (gc mode, nogc enforcement, target) rather than on every native codegen knob, so `JAC_RC_DEBUG_CODEGEN`, `--debug` and the optimization level no longer invalidate the compiler's own cache.
