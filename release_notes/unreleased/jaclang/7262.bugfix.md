- **Fix: narrowing understands membership tests, string literals, and what a literal rules out**: `x in (a, b)` and `x not in (a, b)` now narrow when every element is a literal, and `x == "literal"` now narrows for strings the way it already did for `int`/`float`/`bool`. Excluding a literal no longer deletes the whole type it belongs to, so the branch where `x != "node"` (or `x not in (...)`, or the `else` of `x in (...)`) holds keeps its full type instead of collapsing to `None`; a union of literals still narrows to the members that remain. An f-string is not a literal, so comparing against one narrows nothing.
