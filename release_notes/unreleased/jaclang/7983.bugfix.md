- **Fix: Native `list[str]` decodes correctly across the FFI boundary**: `native_marshal` now models the native string length encoding instead of falling back to `strlen`, so strings carrying an interior NUL survive the crossing, and object fields declared `list[str]`, `dict[str, str]` or `set[str]` decode to strings rather than raw pointer integers. The RC-header offsets, header magic, RC sentinel, string length stamp and `JacStr` descriptor field order now live in `jaclang.jac0core.codeinfo` as the single definition both the native codegen and the marshal layer read. A sealed artifact that predates the new `str_headerless` layout key keeps the `strlen` decode it had before rather than being read as though its strings carried a header.
