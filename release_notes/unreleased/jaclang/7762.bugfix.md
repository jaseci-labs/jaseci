- **Fix: Client builds no longer fail on undeclared runtime deps without a `[client]` table**: the core client runtime/dev dependency closure (including `@tanstack/react-form` and `zod`, which the generated client runtime imports unconditionally) is now always injected into the effective in-memory npm dependency set, so the generated `.jac/client` package.json resolves every runtime import regardless of whether `jac.toml` declares a `[client]` table. Previously the injection was gated on the table while the client build activated from the compiled manifest, so fullstack apps without a `[client]` section failed with `Rollup failed to resolve import "@tanstack/react-form"`. Reading client config still never writes to `jac.toml`.
