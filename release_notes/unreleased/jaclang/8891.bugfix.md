- The analysis cache's interface hash no longer depends on which compile flavour persisted a module: a compile acting on an inferred native placement verdict keeps the analysis-flavour interface on disk instead of overwriting it with native typing, so `jac check` and codegen compiles agree and the dependency cutoff holds across processes; the interface-bytes memo is bounded at closure release instead of cleared, so re-persisting an unchanged module no longer re-ingests its dependencies (a cold littleX precompile had grown from 1927 to 2183 pass runs).
