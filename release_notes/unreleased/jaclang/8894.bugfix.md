- The analysis cache's interface writer keys scopes, symbols, classes, and types by canonical identity inside the module boundary (path, dotted scope, span; a type is a value), so a stale twin of a module kept alive through memoized types is no longer emitted alongside the fresh tree; interface digests are now deterministic across compiles (they changed on every compile of `type_evaluator.jac` before). A tree-demanding compile (`need_full_ast`) no longer disables hydration for every later compile in the same program, module-level comprehension variables no longer leak into interfaces, and verify mode compares interface digests and path-normalized diagnostics.
