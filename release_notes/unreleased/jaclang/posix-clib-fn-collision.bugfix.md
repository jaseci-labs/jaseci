- **Fix: Jac surface function name collides with transitive clib extern (DuplicatedNameError ICE)**: when an imported dep module walks `import from c { def ioctl ... }` into the entry module's LLVM IR and the entry module also defines `def ioctl`, forward-declaring the Jac ability called `ir.Function(..., name="ioctl")` on an existing libc declaration raised `DuplicatedNameError` (e.g. `fcntl.jac` / `prim_fcntl`). The emitter now mangles the Jac symbol to `ioctl.__jacp_<mod>` when a clib extern already owns the bare C name, matching the existing private-fn mangling path.
