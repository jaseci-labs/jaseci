- **Fix: dynamic `[id]` directory routes never matched**: the file-based router translated `[param]` to `:param` for file stems but not for directory names, so a page like `pages/videos/[id]/index.jac` emitted a literal `"/videos/[id]"` path that react-router treats as plain text — the page rendered blank with no error. Directory segments now get the same translation, so `pages/videos/[id]/index.jac` serves at `/videos/:id`.
