- **`jac start --scale` now works from macOS and cross-arch hosts**: the deploy previously executed the downloaded Linux pod runtime on the deploy host to seal the app, failing with `Exec format error` on macOS (and on Linux hosts deploying to a different node arch via `JAC_NODE_ARCH`). The seal and wheel-vendoring steps now run a host-platform build of the same jac channel/version, pods still receive the `linux-<node_arch>` binary, and vendored wheels are pinned to a `manylinux` tag for the node arch instead of inheriting the platform of whatever binary runs pip.
