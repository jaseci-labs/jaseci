- **Native: constructing a class now runs its inherited postinit chain**: the constructor's postinit lookup only matched a method the class declared itself, so a class inheriting its postinit (unitree's `ElseIf(IfStmt)` shape, or any imported class whose postinit lives on an ancestor) silently skipped the chain -- `ElseIf.loc` stayed null and any `elif`/`else` parse on the sealed native parser aborted in `IfStmt.postinit`. The constructor now decides between explicit-init and generated-init semantics the way the bytecode runtime does (the first MRO class carrying its own `init` or its own has-fields decides; an explicit init owns its whole chain), and a generated construction dispatches the MRO-nearest `__post_init__` through the class-routed path that receiver-specializes the body when the owner is not layout-prefix-compatible.
