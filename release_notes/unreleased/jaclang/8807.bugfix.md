- **Intel Macs: this release ships no `jac` binary**: The macOS x86_64 build is currently broken, so this release has no Intel Mac binary attached. There is nothing to install in its place. The macOS binary that did build is arm64 (Apple Silicon) code, and Rosetta translates x86_64 onto Apple Silicon rather than the other way round, so it cannot run on Intel hardware. If you are on an Intel Mac, stay on the last release that has an Intel build; the installer now names it for you and prints the exact command. Apple Silicon Macs, Linux x86_64 and Linux aarch64 are unaffected and install as usual.
- **Fix: the installer says what is wrong instead of guessing**: When a release has no binary for your platform, `install.sh` used to fail on the download with a list of possible causes ("the version does not exist", "a native binary is not available", "network issue"). It now checks the release's own asset list first and tells you which of those it actually is, and for a genuinely missing platform it points at the most recent release that does carry one.
