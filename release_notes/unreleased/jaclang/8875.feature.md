- **`jac guide --nav` and `jac://docs/nav`: the docs navigation is now a first-class surface**: the bundled corpus's `nav.json` (sections, titles, reading order) was readable only by opening the file. `jac guide --nav` prints it as an indented tree with each page's `jac guide` name, `jac guide --nav --json` emits the raw manifest for tooling, `guide_store.nav_manifest()` / `nav_pages()` expose it to Jac programs, and the MCP server lists it as the `jac://docs/nav` resource next to the per-page `jac://docs/*` resources. The in-tree jaclang.org site is the first consumer: its docs section now reads the corpus bundled with the jac binary that serves it, in-process, instead of cloning the monorepo from GitHub, and populates its docs graph once per distinct corpus (a restart on the same binary finds the persisted graph and does nothing).
