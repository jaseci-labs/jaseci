- **Native: a demotion names its cause instead of every read downstream of it**: when the right-hand side of an assignment could not be lowered, the native emitter reported that failure and then reported every later mention of the name it never bound as a fresh `E5092` -- once per read, each blaming a different expression kind (`Name`, `CompareExpr`, `IfElseExpr`, `UnaryExpr`, `BinaryExpr`). A single un-lowerable call therefore produced up to five diagnostics across four subsystems, and the demotion report a sealed build prints named symptoms rather than the one line to fix; the same noise put three of the epic's remaining seal blockers in front of the wrong backend surface. A failed binding now records the names it left slotless (walking tuple targets, and propagating through any binding that reads one of them), and a read of such a name is attributed to the binding instead of re-reported. On the `jac0core/parser/parser.jac` seal closure this takes the `E5092` sites from 167 to 154 with the set of demoted methods unchanged: every removed site was a consequence, and none of them was a lowering gap. Reads whose name a later binding did give a slot are untouched, so a genuine failure elsewhere in the function still reports.
- **Native: union-typed slot reads, comparisons and selects are pinned by value**: `is`/`is not None`, truthiness in condition position, and `a if c else b` over a slot holding a union all lower today, but nothing checked what they *produce*, and an unbox or select that drops the payload compiles cleanly and returns the wrong value. The new `union_slot_ops` suite exercises all three forms over both storages the union rule can pick -- a boxed `jacval` for a mixed member set, the first member's pointer layout for an all-pointer one, and `JacOpt` for `T | None` -- and reads the payload back on every path: the int member as itself, the str member as its negated length, a field off the object on the far side of a `x if isinstance(x, T) else None` select. Truthiness is checked against the falsy payloads (`0`, `""`, `[]`) that distinguish it from a none-tag test, and every function is additionally compared against the sv/bytecode result of the same fixture.
