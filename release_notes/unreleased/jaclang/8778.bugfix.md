- **Fix: `jac run` no longer recompiles a demoted-native module on every run**: a module that prefers native but does not lower (E5092) is demoted to the server codespace, but the verdict lived in a process-local dict, so every `jac run` repeated the native attempt, the server retry, and the type-check prelude behind both, even with a valid JIR on disk. The verdict now persists as a `.nademote` sidecar next to the module's JIR (keyed by the file's mtime and size, under the compiler-generation cache dir, so an edited file or a changed compiler re-tries native), `jac run` skips the native-probe compile when the verdict is server, and a run that compiled through the probe now writes the JIR too (`get_bytecode` persisted nothing on a hub hit). Warm `jac run` of a small demoted file: 0.75 s / 241 MB to 0.18 s / 63 MB.
