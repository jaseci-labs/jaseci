- **Build: seal what you serve, with one reusable record and a `jac seal` front door**: The fused native artifact's claim shrinks to the modules whose code actually executes in a sealed process (the parser, the materializer, and the prefix passes), making "sealed means served" literally true; the linked-but-never-called pass code, the waiver families, the refused-modules table, eleven measurement suites, and three CI lanes (`host-kit`, the source-lane `test-native` twin with its swapfile, `test-reroute-gaps`) that existed to manage that dead weight are deleted. The guards that remain are the ones that execute: the seal's in-compile demotion gate and the corpus canaries. `SEAL_INDEX.json` returns as a single record keyed on the compiler digest, the real source closure, and the waiver digest, so an unchanged tree reuses the sealed library with zero compiles after a fresh load canary. And the whole gate gets one front door: `jac seal <mod.jac>` seals any module as its own unit, `jac seal --compiler` seals the served compiler surface, with `--ir` for the unit's LLVM text and `--debug` for the reason behind every demotion, reroute-native and scratch-safe by default. That front door now narrates itself: the seal is a long opaque pipeline whose every refusal names a phase, so each phase (`reuse`, `stage`, `compile`, `gate`, `layout`, `link`, `canary`, `write`, `index`) announces itself when it opens and closes with its result and what it cost, the purge-and-recompile retry that used to look like a hang is now visible as a retry, a refusal marks the phase that refused before the gate's diagnostic, and the run ends on an artifact/layout/triple block. `jac build --as sealed` inherits the same reporting. The native backend's user-facing warnings -- the seam demotions, the struct-name collision, the linker's unresolved references -- move off raw `sys.stderr` onto the console, so they arrive as real warnings with the rest of the CLI's vocabulary rather than as bare text; the `NA_DEBUG`/`SPECMISS` traces stay raw, since they are grep-anchored developer output.
