- **Fix: `jac check` no longer flags enum metaclass attributes as missing**: accessing `__members__`, `_member_names_`, `_member_map_`, or `_value2member_map_` on an enum class (`StrEnum`, `Enum`, `IntEnum`, or native `enum`) raised a false `error[E1030]: has no attribute`, even though the code ran correctly under `jac run`. These attributes live on the enum metaclass rather than the enum's own MRO, so the checker now synthesizes their types (`dict[str, Enum]`, `list[str]`, etc.) alongside the existing `.name` / `.value` / iteration special cases.
