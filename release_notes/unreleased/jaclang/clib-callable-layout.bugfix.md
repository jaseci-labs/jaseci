- **Fix: `Callable[[...], ret]` clib struct fields are layout-compatible**: The layout pass already treated bare `FuncSignature` annotations as fn-pointer slots, but clib archetypes spell the same ABI as `Callable[[i32], None]` and drew W5032 — blocking native lowering of modules such as `_signal_native.jac` that install C signal handlers through `struct sigaction`. The pass now recognizes `Callable` type annotations as layout-compatible fn-pointer fields and records `is_func_ptr` on their `FieldInfo`.
