- **Fix: the linux/arm64 binary builds again**: The aarch64 outline-atomics helpers are `module asm`, and assembling module asm needs an LLVM asm parser registered for the target being emitted. The executable emit path registered none, so building the launcher stub for linux/arm64 aborted with `LLVM ERROR: Inline asm not supported by this streamer because we don't have an asm parser for this target`. The bundled LLVM shim now registers the asm parsers for all targets, alongside the target infos, target MCs, and asm printers it already registered, so cross-compiling to aarch64 from another host works too.
