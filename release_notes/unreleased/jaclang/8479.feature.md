- **byLLM: per-call usage during streaming tool-calling loops**: a new `usage_step` `StreamEvent` reports usage after each LLM call in a tool-calling loop instead of only at the end, so callers can enforce a per-turn budget mid-turn (`IterationContext` gains `total_cost` alongside `total_tokens`; `llm_timing` events now carry only timing, not usage). Streaming calls, including tool-calling loops, also report more accurate native cost instead of a locally recomputed estimate.
