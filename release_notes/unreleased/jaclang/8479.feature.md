- **byLLM: per-call usage during a streaming ReAct loop (`usage_step`)**: a new `usage_step` `StreamEvent` fires once per LLM call in a tool-calling `stream=True, logging=True` invocation, instead of only once at the very end - useful for enforcing a per-turn budget without waiting for the whole turn to finish. `IterationContext` also gains `total_cost` alongside `total_tokens`.
- **byLLM: more complete native cost on streaming calls**: byLLM opts in to litellm's `include_cost_in_streaming_usage`, and every streaming path - including tool-calling ReAct loops, not just plain text streaming - now benefits from it.
- **byLLM: cache token fields are consistent across providers**: `cache_read_input_tokens`/`cache_creation_input_tokens` are normalized to the same names regardless of provider, defaulting to `0` instead of being silently absent.
- **byLLM: `llm_timing` no longer duplicates  token/cost fields** now that `usage_step` covers them - it carries only `duration_ms`/`iteration`.
