- **Feature: placement facts API and compiler-driven seal**: `jaclang.jac0core.placement_facts` is the single query surface for which codespace(s) a module emits into (`module_spaces`, `is_client_only`, `emits_server_code`, `discover_spaces`, `sealed_spaces_for`). The seal's file list now comes from a placement discovery compile instead of filesystem heuristics, so client-only modules -- pinned *and* markerless-inferred -- are skipped; the pins-as-verdict and path-prefix native bypasses were removed. App seals persist the per-module placement verdict in the sealed `MANIFEST.json` (format 5), and direct `placement_pins` imports are restricted to the solver layer, enforced by a repository test.
