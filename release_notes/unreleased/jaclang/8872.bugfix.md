- **Scale: a fleet enforces one rate limit instead of N**: the rate-limit middleware chose its state backend by reading a `scale_enabled` config key that no loader has ever emitted, so the shared Postgres backend was unreachable in any deploy and every replica kept its own token buckets: at `replicas = N` a client could send `N * per_ip_rpm` requests per minute before a 429, decided by which pod each request landed on, with the factory's own fallback warning sitting in a branch that could never execute. The gateway now asks for shared state explicitly, the dead config read is deleted, and an unreachable store falls back in-process with the existing loud warning instead of silently. Fixes #8333.
