- **Fix: `--scale` deploy seal skips client code again**: The deploy stager now writes the sanitized root and nested `jac.toml` files into the seal stage before the seal runs, so `[placement.pins]` and nested-project scoping are visible at seal time; previously every client module was compiled into pod bytecode and large apps hit the seal timeout. Sealing an app tree without a `jac.toml` now fails loudly instead of silently compiling everything, and the seal timeout is configurable via `[scale] seal_timeout` (default raised from 600s to 1800s).
