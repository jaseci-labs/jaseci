- **Breaking: the `[scale.microservices]` era is deleted, not deprecated (#8823)**: every piece of the old service and client-target surface is gone in one clean break. Config: any `[scale.microservices.*]` table (`routes`, `services`, `enabled`, `client`, `service_files`, the `logs` / `ingress` / `cors` / boot-key infra tables) is now a hard error at `jac.toml` parse time (exit 2) that names the replacement, `[apps.<name>]` tables plus `[scale.gateway]`; `[client] target` and the `JAC_CLIENT_TARGET` env var are replaced by `[apps.<name>] client` (and `--client <target>` as a per-run override); `[serve] base_route_app` and `[serve] cl_route_prefix` are gone (the served app is at `/`, every other client-capable app at `/cl/<app-name>/`); `[project] client_kind` is a parse error (it is an app property, `[apps.<name>] client_kind`); `JAC_ENV` is gone in favour of `--profile` / `JAC_PROFILE` / `[environment] default_profile`. Commands: `jac scale split <module>` and `jac setup microservice` are removed (`jac create --app <name> --kind service`). Runtime: the module-stem keyed `JAC_SV_<MODULE>_URL` env vars become app-keyed `JAC_APP_<APP>_URL` / `JAC_APP_<APP>_ROUTE`; `JacServe.ensure_sv_service`, `JacServe.sv_service_call` and `JacServe.sv_walker_call` are removed from the runtime interface (cross-app calls go through `jaclang.server.sv_client`, which is keyed by provider app name and dispatches to the scale transport when one is registered). Kinds: the enclosing-project kind chain (`_project_kind_chain` in `placement_facts`, which walked every ancestor `jac.toml` for a `kind`) is gone: an app's kind is its `[apps.<name>] kind`, the implicit app's `[project] kind`, or entry-point inference, and a nested `jac.toml` under a workspace is its own project that inherits nothing; and `[project] kind = "mobile"` now means the React Native mobUI app (`client_target = "react-native"`, `client_kind = "mobui"`); the Capacitor web-view shell stays reachable by setting `client = "mobile"` on the app. Examples: `examples/mobui/hello` and `examples/mobui/littlex` are deleted; the mobUI reference is the flagship workspace's `mobile` app (`jac create <name> --awesome`). See [Breaking Changes](../breaking-changes.md).
