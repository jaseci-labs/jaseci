- **Breaking: the `[scale.microservices]` era is deleted, not deprecated (#8823)**: every piece of the old service and client-target surface is gone in one clean break. Config: any `[scale.microservices.*]` table (`routes`, `services`, `enabled`, `client`, `service_files`, the `logs` / `ingress` / `cors` / boot-key infra tables) is now a hard error at `jac.toml` parse time (exit 2) that names the replacement, `[apps.<name>]` tables plus `[scale.gateway]`; `[client] target`, the `JAC_CLIENT_TARGET` env var, and the `--client` flag on `jac run` / `jac build` / `jac setup` are gone: the app's kind decides its client (web-app and web-static render the DOM, desktop wraps it in a webview, mobile is React Native), `--platform` is the only per-run override, and `jac build --as client <app>` builds just the client bundle; `[serve] base_route_app` and `[serve] cl_route_prefix` are gone (the served app is at `/`, every other client-capable app at `/cl/<app-name>/`); `[project] client_kind` and `[apps.<name>] client_kind` are parse errors: every `mobile` app is mobUI and no other kind is; `JAC_ENV` is gone in favour of `--profile` / `JAC_PROFILE` / `[environment] default_profile`. Commands: `jac scale split <module>` and `jac setup microservice` are removed (`jac create --app <name> --kind service`). Runtime: the module-stem keyed `JAC_SV_<MODULE>_URL` env vars become app-keyed `JAC_APP_<APP>_URL` / `JAC_APP_<APP>_ROUTE`; `JacServe.ensure_sv_service`, `JacServe.sv_service_call` and `JacServe.sv_walker_call` are removed from the runtime interface (cross-app calls go through `jaclang.server.sv_client`, which is keyed by provider app name and dispatches to the scale transport when one is registered). Kinds: the enclosing-project kind chain (`_project_kind_chain` in `placement_facts`, which walked every ancestor `jac.toml` for a `kind`) is gone: an app's kind is its `[apps.<name>] kind`, the implicit app's `[project] kind`, or entry-point inference, and a nested `jac.toml` under a workspace is its own project that inherits nothing; and `kind = "mobile"` is the React Native mobUI app. **The Capacitor web-view mobile shell is deleted** (the `mobile` client target, `jac setup mobile --platform`, the `android/` and `ios/` scaffolds, `[client.mobile]`, `JAC_MOBILE_DEV_HOST`, `JAC_MOBILE_SETUP_PLATFORM`, `JAC_MOBILE_VITE_PORT`): a web app goes on a phone as a PWA, a native app is a `mobile` app over the shared core. PWA and CEF are no longer client targets either: a `[client.pwa]` table turns the web build into a PWA (`jac setup pwa` and `--client pwa` are gone), and `[desktop] engine = "cef"` selects Chromium for a `desktop` app (`--client cef` is gone; both engines build into `.jac/client/desktop/`). Target-scoped npm tables are keyed by the kind's client name: `[dependencies.npm.mobile]` replaces `[dependencies.npm.react_native]`. Programmatic: `TargetType`, `normalize_client_target`, `CLIENT_TARGETS`, `TargetFactory`, `app_client_target`, `AppConfig.client` / `client_kind` / `effective_client`, `KindSpec.client_target`, `CompileOptions.client_kind`, and `jaclang.project.client_kind` are gone; `KindSpec.ui` (`dom` / `mobui`), `kind_ui` / `kind_has_client` / `kind_is_mobui`, `AppConfig.ui()`, `target_for_kind` / `target_for_app`, `CompileOptions.ui`, and `jaclang.project.mobui_scope` replace them; `JacClientCompiler.compile(..., native=True)` replaces `target_name="react-native"`. Examples: `examples/mobui/hello` and `examples/mobui/littlex` are deleted; the mobUI reference is the flagship workspace's `mobile` app (`jac create <name> --awesome`). See [Breaking Changes](../breaking-changes.md).
