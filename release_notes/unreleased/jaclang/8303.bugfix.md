- **Scale: a config-only deploy now reaches running pods**: secret sections are stripped from the bundle before it is packed and the Secret is referenced by a constant name, so a deploy that changed only configuration produced a byte identical pod template. The patch was a no-op, no rollout happened, and the app kept serving the previous values while the deploy reported success. The pod template now carries a `jac-scale.config-hash` annotation derived from the resolved secrets, so a config change is a template change and the fleet rolls. Apps with no secrets are unaffected, since the hash of an empty map is constant.
