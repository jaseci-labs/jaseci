- **New `jac precompile` verb replaces script-style precompiler invocation**: the JIR precompile/seal engine is now dispatched as a hidden CLI verb, `jac precompile <dir> [--seal|--seal-compile|--seal-finalize] [--debug-src] [--jobs N]`, instead of being run as `jac run dist/precompile_bytecode.jac ...`. All internal callers route through it: the `jac build --as sealed/jab` child, the payload build's boot shim, and the scale injector's pod-binary seal step (which no longer path-probes the binary's tree for the sealer script; a seal binary that predates the verb falls back to its own vendored script with a warning). The engine module keeps its location and remains directly importable, so compiler digest roots and sealed-image expectations are unchanged.
