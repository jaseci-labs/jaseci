- **Fix: shadcn pages no longer load blank on a bad hugeicons name**: `@hugeicons/core-free-icons` zero-pads every numeric suffix, but the `jac-shadcn-components` skill guide listed `Calendar1Icon` and `Clock1Icon` as single-digit, so agents wrote names the package does not export. A wrong named import is not a compile error -- `jac check` and the build both pass, and it fails only at page load, where a missing export takes down the whole module and leaves the page blank. The guide now lists the padded names and states that there is no single-digit form. Six registry components (`accordion`, `calendar`, `combobox`, `command`, `navigation_menu`, `select`) shipped with the same bad names and blanked the page on install; they now import the real ones.
