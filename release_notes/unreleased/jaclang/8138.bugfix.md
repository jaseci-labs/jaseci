- **Fix: shadcn pages no longer load blank on a bad hugeicons name**: `@hugeicons/core-free-icons` zero-pads every numeric suffix, but the `jac-shadcn-components` skill guide listed `Calendar1Icon` and `Clock1Icon` as single-digit, so agents wrote names the package does not export. A wrong named import is not a compile error, so it passes `jac check` and the build and blanks the page at load. The guide now lists the padded names, and six registry components (`accordion`, `calendar`, `combobox`, `command`, `navigation_menu`, `select`) that shipped with the same bad names import the real ones.
