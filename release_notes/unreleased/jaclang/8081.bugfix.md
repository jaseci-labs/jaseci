- **Fix: gateway no longer replays request bodies across services**: builtin passthrough routing (`/walker`, `/function`, `/webhook`, `/user`, `/sso`, `/api-key`) used to forward a buffered request body to every service in turn until one stopped returning 404, so a non-idempotent request could be delivered, and for replicated identity endpoints executed, more than once. The gateway now resolves the owning service from its learned route table before forwarding and delivers unsafe requests exactly once; the try-each-service probe is kept only for `/jobs`, `/cl` pages, and safe methods (GET/HEAD/OPTIONS), where a 404 is a pre-side-effect routing signal.
