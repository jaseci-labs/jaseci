- **Guaranteed tail calls on the native backend**: `return f(...)` in eligible functions is now compiled as a true tail call, so deeply recursive code (self- or mutual recursion, accumulator loops, state machines) runs in constant stack space instead of overflowing at depth, at every optimization level. Calls that cannot safely be tail calls (for example inside a `try` block) automatically keep the normal behavior. Set `JAC_TAILCALL=0` to disable.
