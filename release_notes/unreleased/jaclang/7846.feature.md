- **Faster, order-preserving native `dict`**: dictionaries in natively compiled code are back to constant-time inserts and lookups, so building or reading a large dict no longer slows down as it grows. Iterating a dict (and `keys()`, `values()`, `items()`, `repr`, and JSON output) now visits keys in the order they were inserted, matching Python. Deleting or popping string keys is also fixed (it could previously crash).
