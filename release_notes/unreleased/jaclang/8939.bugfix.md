- A macOS shared library built by `jac nacompile --shared` resolves its `import from c` symbols from the process that loads it (flat lookup) instead of binding them to libSystem, and the C library's darwin name normalizes to libSystem instead of a nonexistent `libc.dylib`. The compiler kernel declares the CPython C API that way, so every macOS build of 0.37.3 died at first run with `Symbol not found: _PyDict_GetItem`.
