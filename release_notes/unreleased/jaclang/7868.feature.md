- **Client: custom `<script>` tags in the generated `index.html` head**: `[client.app_meta_data]` now takes a `scripts` key, so analytics snippets, third-party SDKs, and preloaded libraries can be declared in `jac.toml` instead of injected at runtime after the bundle boots. Each entry takes `src` or an inline `content` body, plus the boolean flags `async`/`defer`/`nomodule`, the valued attributes `type`/`crossorigin`/`integrity`/`referrerpolicy`/`nonce`/`id`/`fetchpriority`, and `data_*` keys that fold to `data-*`. Values are HTML-escaped, unlisted attributes are dropped, and a literal `</script>` in an inline body cannot close the tag early. Applies to `jac build`, `jac start`, and `jac start --dev`.
