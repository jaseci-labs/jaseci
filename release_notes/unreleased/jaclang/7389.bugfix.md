- **Perf: Module cache probes hash keys once and memoize client-kind lookups**: `get_bytecode` computes a module key at most once per fallthrough: the probe returns the freshly computed key for reuse by the precompiled-JIR check and both cache-write paths, eliminating up to five redundant content hashes per cold compile. Per-path `client_kind` resolution is memoized behind the backing `jac.toml`'s content hash (self-invalidating on config edits, with `clear_module_client_kind_cache()` for file-watchers), and a single annex discovery is shared between the mtime fast path and the modkey check.
