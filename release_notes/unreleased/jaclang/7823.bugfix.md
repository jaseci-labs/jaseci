- **Fix: Editor hover tooltips no longer show stray quote characters**: Hovering a symbol in a `.jac` file rendered every part of the tooltip wrapped in single quotes -- `'('public variable') 'append': '<function ...>'` instead of `(public variable) append: <function ...>` -- with the same characters opening each following line, including the `placement:` line. The quote characters were literal text inside the strings that build the tooltip, so they appeared for every symbol in every file. Three language server log messages carried the same artifact and are corrected with it.
