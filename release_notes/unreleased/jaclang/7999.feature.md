- **byLLM: Stream tool-argument fragments as `tool_call_delta`**: `by llm()` now surfaces tool-call arguments while they are still being generated, instead of only once the whole call is complete, so a caller can show which file is being written during a long write. Fragments are coalesced (on size, elapsed time, and a per-call cap) so a provider that splits an argument into hundreds of pieces cannot flood a consumer, and the tool name is published as soon as it is known. The event is display-only: execution still uses the call rebuilt by `stream_chunk_builder`, so a partial fragment can never reach a tool, and consumers that ignore the new event are unaffected.
