- **byLLM: finish_tool-related calls no longer break the Anthropic prompt cache**: `_stream_final_answer`, `_force_final_answer`, and `_attempt_recovery` all shrank the tools array down to `[finish_tool]` before their respective follow-up calls; since Anthropic's cache breakpoint sits on `tools[-1]` and tools serialize ahead of the message list, that swap invalidated the cached prefix for the whole conversation, rebilling the entire accumulated context at the cache-write rate. All three now leave the tools array untouched: `_stream_final_answer` already forbids further tool calls via `tool_choice="none"`, and `_force_final_answer`/`_attempt_recovery` now force `tool_choice` onto `finish_tool` specifically instead of narrowing the tools list, which also guarantees a validated typed answer where it was previously only best-effort.
