- **`jac check` no longer reports different diagnostics for relative and absolute paths**: `is_bootstrap_compiled_module` tested for `/jaclang/jac0core/` with a leading separator, so a relative path never matched and `jac0core` modules lost their ambient-import carve-out -- the same file reported `E1125` when checked as `jaclang/jac0core/passes/jcir_gen_pass.jac` and reported nothing when checked by absolute path. CI's scoped mode feeds relative paths from `changed-jac.txt`, so any PR touching a `jac0core` module hit it. The bootstrap compiler does not inject ambient names, so `E1125`'s premise that "generated code re-imports it automatically" does not hold there and removing the import breaks the module at import time with a `NameError`.
