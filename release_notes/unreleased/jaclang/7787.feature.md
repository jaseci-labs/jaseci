- **Database on/off switch**: `[scale.database] enabled = false` runs an app without Postgres entirely - nothing is provisioned in Kubernetes, no `JAC_DB_URL` is injected, and the runtime falls back to local storage. Setting `[scale.database] url` (or `JAC_DB_URL`) now really skips in-cluster provisioning as documented: the deploy provisions no StatefulSet and injects the external url into app pods instead. The legacy `[scale.kubernetes] postgres_enabled` flag keeps working; zero-config deploys still provision Postgres exactly as before.
