- **Fix: a `jac-version` range pin resolves to a jac release, not a jaseci tag**: The release listing accepted every non-prerelease `v*` tag, so the retired jaseci meta-package releases stayed in the candidate set; they are numerically larger than every jac tag, so `>=0.37.3` resolved to `2.3.28` and the deploy aborted on a release shipping no matching binary. A tag is now a candidate only when it carries a `jac-<tag version>-<platform>` asset, the same contract the download already relies on, and draft releases are skipped.
