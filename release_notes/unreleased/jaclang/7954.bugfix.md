- **Fix: native `//`, `%`, and `divmod()` for negative operands**: integer floor division and modulo now use CPython floor semantics (matching sv/cl and native float `//`) instead of LLVM truncate-toward-zero `sdiv`/`srem`; float `%` no longer uses C `fmod` dividend-sign behavior; `divmod()` and `//=` / `%=` route through the same helpers. The bundled `na_stdlib/datetime.jac` no longer needs its `_fdiv`/`_fmod` truncation workarounds.
