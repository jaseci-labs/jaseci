- **Feature: Per-transform GraphMend toggles**: Each GraphMend transform (trap, where, defer) can be disabled individually via `jac run --graphmend-disable`, the `[run]` section of `jac.toml` (`graphmend`, `graphmend_scope`, `graphmend_disable`), or `CompileOptions(graphmend_disable=[...])`, with explicit CLI flags taking precedence over `jac.toml`.
