- **Refactor: a mixin family states the surface its parts share**: The 44 `NaIRGen*` objects and the `JacAPIServer*` parts are each one class split across many files, composed by a single pass or server object, and they call each other's methods through `self`. Nothing declared that, so each part was checked in isolation and every sibling call read as an attribute that does not exist. The shared surface is now declared abstractly on the base each family already had (431 signatures for `NaIRGenState`, lifted verbatim from the sibling that declares them), so a cross-part call type-checks. No implementation moves and no runtime behaviour changes; `NaIRGenPass`, `JacAPIServer` and `MicroserviceGateway` all still load with no unimplemented abstracts. na_ir_gen drops from 5,491 to 990 type errors and `scale/server` from 459 to 196.
- **Fix: an inferred attribute widens its literal, the way an inferred local already does**: `self.linkage = ''` in a constructor pinned the attribute's declared type to `Literal[""]`, so a later `x.linkage = "private"` was rejected as `Cannot assign Literal["private"] to Literal[""]`. Written as a local, `x = ''` followed by `x = "private"` has always been accepted, because the local branch of the inference widens the literal and the attribute branch did not. Both are declarations inferred from an assignment, so both widen now. An annotated attribute is unaffected, since the annotation is read before this branch.
