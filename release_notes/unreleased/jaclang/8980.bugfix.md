- **No-GC ownership transfers preserve lifetimes**: Moving an optional owned local clears its source and drops an overwritten destination. Returning a string borrowed from a local container copies its storage before the container is destroyed, preventing use-after-free.
- **Native entry errors remain fatal after symbol qualification**: Unhandled errors in native executables report their diagnostic and exit unsuccessfully in both object and bitcode link modes. Diagnostics are flushed before aborting so redirected output is preserved.
- **Native cache identity follows build settings**: The compiled `flow for` thread default participates in the codegen fingerprint, and unit products retain their target and codegen identity.

- **Compiler session ownership and import reuse**: Programs own mutable syntax and type state while sharing immutable catalog bytes. Python star imports use the dependency-scope loader, avoiding repeated full compilation through import cycles; hydrated imports preserve their lazy type providers. Verification sessions release their temporary analysis state.
- **Native socket portability**: Darwin socket calls use the platform's errno accessor, address layouts and IPv6 family. Module attributes remain accessible when an exported class shares the module's name.
- **Client graph filters**: Chained graph-filter expressions reuse the existing predicate lowering, matching traversal filters.

Native JIR sections retain separate target and codegen variants, and cache writes lock the complete merge transaction. Concurrent native and bytecode builds no longer evict shared runtime products or lose unrelated sections. Kernel builds and toolchain installs reuse the same bootstrap-safe file-lock primitive.
