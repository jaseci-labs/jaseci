- **Scale: a configured admin username reaches the Prometheus scrape config**: `KubernetesConfig.from_dict` enumerates its kwargs by hand and `admin_username` was the one declared field missing from the enumeration, so the value the loader emitted from `[scale.admin] username` was silently reset to `'admin'` on the way to the manifest path, and every scrape 403'd whenever a different admin username was configured. `from_dict` now carries the field, and a fixed-point regression test walks every `to_dict` key through the round-trip so the next hand-enumeration gap fails a named assertion instead of landing silently. Fixes #8401.
