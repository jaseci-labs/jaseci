- **`py_ctx_func` is now `expr_ctx`, an `ExprCtx` enum**: unitree name nodes no longer carry `ast3.Load`/`ast3.Store` class references. Pass code reading or stamping expression context migrates from `nd.py_ctx_func = ast3.Store` to `nd.expr_ctx = ExprCtx.STORE` (import `ExprCtx` from `jaclang.jac0core.constant`), and `UniScopeNode.update_py_ctx_for_def` is renamed `update_expr_ctx_for_def`. Code emitting Python AST maps the enum through `PyastGenPass.py_ctx(nd)`. Importing `parse` from `jaclang.jac0core.parser.parser` also moves: use the `jaclang.jac0core.parser` package export or `jaclang.jac0core.parser.frontend`.
