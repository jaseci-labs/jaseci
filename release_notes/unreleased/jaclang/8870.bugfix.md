- **Scale: declared `[scale.kubernetes]` autoscaler bounds reach the rendered autoscaler**: `min_replicas`, `max_replicas`, `cpu_utilization_target` and `memory_utilization_target` were carried correctly onto the config object and then ignored, because `_get_autoscaler_config` hardcoded its fallbacks, so every deploy got `min 1 / max 3 / cpu 50 / memory 80` regardless of what its `jac.toml` says. The autoscaler path now layers per-service `hpa` keys over the config-level bounds over the built-in defaults, the same resolution `_build_resources` already applies to the resource fields. The keys are app-wide defaults and apply to every service in the fleet, the gateway included. Fixes #8850.
