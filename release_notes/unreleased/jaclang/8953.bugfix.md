- **Token usage reaches the caller from every `by llm()` shape (#8462, PR #8953).** byLLM recorded usage on the shared model instance and only read it back on the `stream=True, logging=True` path; plain non-streaming calls, streaming without logging, and the async no-tools paths computed the same numbers and dropped them. Usage now lives on the invocation itself, every dispatch path records it, and the `register_agent_callback` record carries a `tokens` field with the same `total` and `per_call` shape as the `usage` stream event. The async no-tools shapes now emit telemetry too.
