- **Native: `isinstance` against an imported class no longer demotes**: candidate vtables were enumerated from the archetypes the module being compiled defines, and every vtable global was emitted with `private` linkage, so a check against a class owned by another module found nothing to compare against and the whole call site fell back with `E5092`. Candidates now come from the layout registry's program-wide class hierarchy, an imported candidate's vtable is referenced as an external global sized from its defining module's layout, and the defining module's vtable global is externally visible so the reference resolves at link time. Object construction takes the same route, so an imported class instantiated by the importer now stores its vtable pointer instead of leaving the slot null, and the `match` class-pattern check shares the same candidate lookup. Method indices are deliberately not recorded for an imported class, so cross-module dispatch is unchanged. Measured on the `parser.jac` closure: 46 native seams down to 27, with every `isinstance` seam gone.
