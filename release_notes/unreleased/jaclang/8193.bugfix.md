- **Native seal: a `dict` the materializer cannot key crosses as `None` instead of a fabricated int**: the seal-time materializer generator chose its dict-key constructor with `kt if kt in _SCALARS else "int"`, so a key type that is not `int`/`bool`/`float`/`str` was carried across the crossing by calling `PyLong_FromLongLong(key)` -- minting a Python int out of whatever the key actually was. The fallback had never fired, because no materialized field had a non-scalar dict key. Giving `type` a layout (#8161) made `UniNode.__sub_node_tab: dict[type, list[UniNode]] | None` a native field rather than a foreign one the generator skipped, so the generator began emitting the real dict loop for it and the dormant fallback fired on the `type` key, once in each of the 152 emitted node classes: `build-jac` failed on all three platform legs with 456 occurrences of `error[E1053]: Cannot assign type to parameter 'v' of type int`, taking `test-native-aarch64` and `test-native-macos` down with it. `emit_dict` now refuses a key type it has no CPython constructor for -- the field crosses as `_py_none()` and the shape is recorded in the generator's warnings, which is the same answer a dead or foreign field already gets and the same value this field carried in the last green build. It is the congruent answer rather than merely a safe one: `__sub_node_tab` is a lazily built index over `kid`, `None` is its post-init value on a freshly parsed tree, and the Python side rebuilds it identically on first access; an empty dict would instead claim the index was built and empty, and `get_all_sub_nodes` would answer from it.
- **Native seal: the generated materializer's emitters are gated at pull-request speed**: `compiler/native_materialize.jac` is generated inside the seal and is gitignored, and `jac-check` on a pull request is scoped to the `.jac` files that changed, so nothing short of the full seal in `build-jac` ever compiled it and a generator emitting a call it could not type-check reached `main` green. `tests/utils/test_gen_native_materialize.jac` drives the emitters directly with no native compile, pinning that a non-scalar-keyed dict crosses as `None`, that the dropped shape is recorded rather than emitted silently, and that scalar-keyed dicts still carry both key and value.
