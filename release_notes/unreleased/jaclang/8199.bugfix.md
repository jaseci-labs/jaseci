The native seal's parse parity canary now reports what diverged instead of dumping both trees. A materialized module unparses to a single line, so the old line-index report could only ever say "diverged at line 1" and then print both full texts. The report now gives the character offset, line and column of the first difference, every differing token up to six with a window of context on both sides, and the symbol-name fingerprint comparison alongside the unparse one. On failure it also runs an ident-derivation probe that parses a described test plus a bare `test { }` through both tiers across nine description shapes, so a generated-test-ordinal divergence names the derivation step that disagrees. `JAC_NA_DEBUG=1` still dumps both unparsed texts in full.
