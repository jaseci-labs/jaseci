The native seal's parse parity canary now reports what diverged: the character offset, line and column of the first difference, the first differing token with a window of context on both sides, and the symbol-name fingerprint comparison alongside the unparse one. A materialized module unparses to a single line, so the old line-index report could only ever say "diverged at line 1" and then print both full texts twice over. Setting `JAC_NA_DEBUG=1` still dumps both unparsed texts in full.
