- **Graph filter predicates no longer crash the checker**: A comparison inside `[?...]` whose left operand was not a bare `Name` -- a tuple, a call, a literal expression -- raised `AttributeError: 'TupleVal' object has no attribute 'value'` out of the type evaluator instead of reporting. Filter operands are now bound through a single path that admits a field name or a tuple of field names (the shape keyset pagination needs), resolves every name to a real member, and reports anything else as `E5094` at check time under the same code and wording codegen uses. Field names in a composite key are bound before arity is validated, so an arity mistake reports once instead of cascading into `W2001` noise for each name.
