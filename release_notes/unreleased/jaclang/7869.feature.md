- **Feature: Process-scoped index projection -- the warm path for graph queries**: Completeness-marked nodes keep their typed adjacency and predicate columns as process-resident index rows (buffer-pool semantics, ~100 bytes/node, never objects), so repeat queries across requests resolve in-process instead of round-tripping the storage engine: session lookups drop from ~24ms to ~4ms and untyped page slices to sub-millisecond against a Redis+Mongo scale stack, while `deserialized == |result|` still holds. Warming is size-capped (`JAC_PROJECTION_WARM_CAP`) and converges in one touch per frontier. Coherence is contractual: own writes evict synchronously from the commit path, cross-pod writes evict via the existing per-anchor invalidation bus, any bus (re)connect flushes all marks, a subscriber heartbeat detects wedged connections, and a TTL (`JAC_PROJECTION_TTL`, default 10s) bounds worst-case staleness; stale-page admits self-heal at winner verification. `GraphQuery(level='fresh')` bypasses the projection for strong reads; `JAC_PROJECTION=0` disables it.
