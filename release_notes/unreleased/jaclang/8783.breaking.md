- **Breaking: one dev-loop status document, new `/__build_status` shape**: `.jac/client/.jac-dev-status.json` and `.jac/client/.jac-build-error.json` are replaced by a single `.jac/client/.jac-status.json` holding `{"status": ..., "diagnostics": [...]}`, and `GET /__build_status` returns that shape on both the core server and the scale gateway -- the old `{"status": ..., "error": {"file", "message", "source"}}` payload is gone. The dev Vite plugin now forwards raw payloads to `.jac/client/.jac-client-events.json` instead of deriving files itself (`jac-dev-status.js` is now `jac-client-events.js`). `HotReloader.record_error` takes the compiler's own diagnostics instead of a flattened string, and `format_client_error_log` is removed. Tooling that polled `/__build_status` or read either retired file must read the `diagnostics` list (each entry carries `code`, `file`, `line`, `column`, `message`, `help` and a pre-rendered `rendered` string).
