- **Fix: comparing an optional to a number no longer erases its type**: after `if x == 0` (or `x != 0`) on a value typed `int | None`, the checker treated `x` as `None` for the rest of the function, so later `is None` guards reasoned from the wrong type and diagnostics named the wrong one. Comparing against `""` on a `str | None` was unaffected, so the two spellings disagreed. A comparison against a value now narrows only on the branch that confirms the value, which is what it tells you; the useful direction of each form is unchanged.
