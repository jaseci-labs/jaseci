- **Serve: streamed generators now run under the caller's root**: a `def:pub` (or walker `report`) generator served as SSE executed after the request context was torn down, so its body silently fell back to the boot context's empty superroot: reads saw an empty graph and writes made after a `yield` were never committed. Generator results are now bound to the request's execution context for the stream's whole life; sync producers run on a dedicated per-stream thread (off the shared request pool), the stream's writes commit before the terminating `event: end` frame, and disconnected or erroring streams close their producer promptly without rolling back the shared session. Webhook walkers that report a generator now stream instead of crashing.
