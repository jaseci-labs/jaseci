- **A program's native stdlib imports stay in that program**: a module under `runtime/na_stdlib/` imported by a checked or run program was routed into the process-global self-host program the compiler keeps for its own modules, so a pooled `jac check` worker carried its type memos from one file into the next and intermittently failed `na_stdlib/urllib/request.jac` with `E1001: Cannot assign <Unknown> to bytes` on a rerun-green tree (#8828). The native stdlib now resolves into the importing program, whose closure is released after every file. Also fixes every client build raising `'AnalysisLedger' object has no attribute 'get'` after #8825 and #8881 landed side by side.
