- **`int` and `float` join the fixed-width lattice instead of sitting beside it** (#8665): `int` is the signed 64-bit machine integer and now behaves exactly as `i64`; `float` is binary64 and behaves exactly as `f64`. The lattice no longer answers differently depending on how the same machine type is spelled, and `shapes_widen_to` loses five name-string special cases. **Breaking:** `u64 -> int` needs a cast for the same reason `u64 -> i64` does -- previously it was implicit, and because the native lane lowers `int` as `i64`, a `u64` past 2^63 arrived negative there while the server kept it positive, with no diagnostic on either lane. `int -> i64`, `int -> f64`, `i64 -> f64` and `u64 -> f64` are relaxed to match their existing `int`/`float` spellings. A float literal past the target's range is the new **`E1130`** rather than a silent `inf` (`f32 = 1e60`, `f64 = 1e400`); precision loss inside the range is still accepted.
