- **Test hardening for jac-scale**: The scale test suite now runs against real infrastructure instead of hand-rolled fakes and mocks of its own components. Redis, S3, GCS, Firestore, and Mongo-backed paths use real containers/emulators, SSO and WebSocket auth run against a real `UserManager`, and previously-untested modules (state-backend factory, service URLs, k8s ops helpers, SSE framing) gained coverage. A CI gate blocks new test anti-patterns, and the Kubernetes end-to-end suite now runs on scale changes.
