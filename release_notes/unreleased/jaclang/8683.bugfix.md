- **Fix: repeated compiles in one process no longer grow without bound**: each native compile left its entire parsed tree and generated code resident, about 2.9GB and 15 million objects per compile, because symbol reference lists held the nodes alive after the compile that created them was finished. A symbol now tracks its references without keeping them alive, so a finished compile is released: repeat compiles hold steady at roughly 14 thousand objects instead of 15 million. This is what made the native test lane run the machine out of memory, and it also affected editors and any long-running process that compiles repeatedly.
