- **Feature: chunked JIR with hydrate-on-demand for stubs and opt-in `.jac` modules**: the JIR format grows a chunked layout (FORMAT_VERSION 19) that defers each top-level declaration subtree into its own id span, so a stub loads only its eager tier (module shell plus symbol table) up front and materializes class and function bodies the first time they are touched. A hydrate-on-demand reader serves these chunks lazily with cross-chunk cascade on node refs, and the `JAC_LAZY_JAC` opt-in extends the same chunking to eligible `.jac` dependency modules (scoped away from bootstrap and self-hosting modules via `is_jac_lazy_eligible`). On-demand hydration is off by default; the disk cache keeps its content-keyed validity so a rewritten stub with preserved mtime cannot serve stale types.
