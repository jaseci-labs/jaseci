- **Fix: py2jac crashes on complex literals, adjacent f-strings, and lambda IIFEs** (#7990): `PyastBuildPass` now emits `complex(re, im)` for Python complex constants instead of ICE-ing, folding additive forms like `1 + 2j`, `2j + 1`, and `1 + 2j + 3` into a single `complex(...)` call so native lowering succeeds; non-finite float/imaginary parts use overflow literals (`1e309`) or `float('nan')` instead of bare `inf` names; folded adjacent f-string constants store semantic interior content rather than mangled source spans; complex literals in `match` value patterns emit **E5044** with rewrite guidance; and `UnparsePass` parenthesizes compound call targets (lambda, ternary, binops, and related forms) so forms like `(lambda x: x + 1)(10)` round-trip as valid Jac.
