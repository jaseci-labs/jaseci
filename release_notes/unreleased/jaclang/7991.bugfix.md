- **Fix: py2jac crashes on complex literals, adjacent f-strings, and lambda IIFEs** (#7990): `PyastBuildPass` now emits `complex(re, im)` for Python complex constants instead of ICE-ing, folding additive forms like `1 + 2j` into a single `complex(...)` call; folded adjacent f-string constants store the merged semantic string value rather than mangled source spans so multi-line adjacency no longer crashes the lexer; and `UnparsePass` parenthesizes lambda call targets so `(lambda x: x + 1)(10)` round-trips as valid Jac.
