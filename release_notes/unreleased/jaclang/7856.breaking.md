- **Breaking: Queries are data -- closed graph-query IR, id-space planner, storage-owned graph index**: Edge-reference expressions now compile to a `GraphQuery`/`QHop`/`QPred` IR (types as classes, predicates as data, comparators evaluated once) resolved in id space: the storage engine answers type-narrowed hop rows and predicate filters inside its own indexes (`graph_edges`/`graph_types` in SQLite; edge docs plus a type-ancestry collection in Mongo), the request overlay guarantees read-your-writes, and objects deserialize exactly once per query, for winners. Every filter spelling (`[-->[?:T, p]]`, `[-->[?:T]][?p]`, `[-->][?:T][?p]`) is now equivalent and correct.
- **Breaking: Closed filter sublanguage**: `[?...]` predicates on graph references are pure (`field <op> value`, op in `==`, `!=`, `<`, `<=`, `>`, `>=`, `in`; evaluated zero-or-more times, comparators once). Anything else is compile error `E5094` with a fix-it, never a silent drop. Plain list filtering via `[?...]` on non-graph values is unchanged.
- **Breaking: Removed**: the callable-filter `refs()`/`OPath`/`ObjectSpatialPath` query API, the `TopologyIndex` blob and `topology_index_data` anchor field, `topo_utils` mutation hooks, the `[run] topology_index` config knob, and the dormant `QueryPlan`/`capabilities`/`execute_plan` machinery. Existing databases auto-reindex from committed anchors on first open (`db_format_version` 2).
