- **Fix: jac native now narrows optionals and boxed unions flow-sensitively**: a use that a test proves non-None (or proves to be a given union member) reads the payload directly, with no runtime tag check, exactly as the sv/bytecode backend already did. Previously `ids[0]` on a guarded `list[int] | None` did not lower at all (`Type of #1 arg mismatch: %"List.i64"* != %"JacOpt.1"`, out of `_codegen_index`) and `x + 1` inside `if isinstance(x, int)` on a boxed value crashed the emitter; `len(ids)` did lower but paid a checked unwrap the guard had already made unreachable. `is None` / `is not None` / `!= None` guards, truthiness, if/else, early `return` / `continue` / `raise` guards, and `isinstance` are all covered, for pointer-payload and scalar-payload optionals alike. The narrowing fact is read off `Expr.type`, where the type checker already stamps it, rather than re-derived by a second analysis in the backend, so native and sv agree by construction. Uses with no proving test keep the checked unwrap they have today. Guarded scalar optionals also get faster: the guard's own tag check is no longer paid twice.
