- **Fix: jac native now narrows optionals and boxed unions flow-sensitively**: a use that a test proves non-None (or proves to be a given union member) reads the payload directly, with no runtime tag check, exactly as the sv/bytecode backend already did. `if ids is None { return 0; } return len(ids);` on a `list[int] | None` previously did not lower at all (`Type of #1 arg mismatch: %"List.i64"* != %"JacOpt.1"`), and `x + 1` inside `if isinstance(x, int)` on a boxed value crashed the emitter; both now lower. `is None` / `is not None` / `!= None` guards, truthiness, if/else, early `return` / `continue` / `raise` guards, and `isinstance` are all covered, for pointer-payload and scalar-payload optionals alike. The narrowing facts come from the type checker's existing `TypeEvaluator.get_narrowed_type` rather than a second analysis in the backend, so native and sv agree by construction. Uses with no proving test keep the checked unwrap they have today, and a rebind or a loop back-edge re-widens the value so None is never read as a payload. Guarded scalar optionals also get faster: the guard's own tag check is no longer paid twice.
