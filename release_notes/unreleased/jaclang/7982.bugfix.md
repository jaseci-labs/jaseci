- **Fix: Route native call arguments, receivers, and unpack stores through the optional coercion**: Method call arguments, method receivers, and tuple-unpack assignment stores now go through `_coerce_type`, so idiomatic optional-typed jac such as `x: list[int] | None = None; x = []; x.append(1);` lowers natively instead of crashing the codegen pass or producing IR that fails verification.
