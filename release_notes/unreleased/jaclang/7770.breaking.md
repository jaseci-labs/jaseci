- **Breaking: The `.na.jac` filename marker is retired**: native placement is inferred (or forced), never spelled in the filename. A plain `.jac` module classifies native through the placement solver under the default `[build] default_codespace = "native"`, demoting to the server codespace with a note when it cannot lower; an explicit AOT build (`jac nacompile`, `jac build --as native`, or `CompileOptions(force_codespace='native')`) forces the placement so lowering problems stay loud errors. `pub` still anchors a standalone module to the server, but a module pulled in as a native *dependency* may use `pub` freely as its C-ABI export marker, and the inferred cl->na edge claims only anchored targets (ownership tags, clib decls, native imports) -- unanchored `pub` modules bridge over RPC. Any leftover `.na.jac` file now fails loudly with a rename hint; the bundled native stdlib is native by location (per-OS variants are `<name>.<os>.jac`), `kind = "cli-native"` is always explicit, the `.na.impl.jac` annex variant is gone, and `JAC_NATIVE_LEXER` is removed with the dual lexer path it selected.
