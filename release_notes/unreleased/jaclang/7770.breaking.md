The `.na.jac` filename marker is retired: native placement is inferred (or
forced), never spelled in the filename. A plain `.jac` module classifies
native through the placement solver under the default
`[build] default_codespace = "native"`, and demotes to the server codespace
with a note when it cannot lower. An explicit AOT build (`jac nacompile`,
`jac build --as native`, or `CompileOptions(force_codespace='native')`)
forces the placement so lowering problems stay loud errors. `pub` still
anchors a standalone module to the server, but a module pulled in as a
native *dependency* may use `pub` freely as its C-ABI export marker -- the
old native-library idiom is unchanged. Any leftover `.na.jac` file now fails
loudly (compiler, importer, and `jac nacompile`) with a rename hint; the
bundled native stdlib and every in-tree native module are renamed to plain
`.jac`, and the `.na.impl.jac` annex variant is gone. `JAC_NATIVE_LEXER` is
removed with the dual lexer path it selected.
