- `async def ... by llm(stream=True)` no longer raises `TypeError: 'async_generator' object can't be awaited` on every LLM class except `Model`: `BaseLLM.model_call_with_stream_async` was an async generator while its only caller, `adispatch_streaming`, awaits it before iterating, so `MockLLM`, `LocalLLM`, `ModelPool` and any user-defined `BaseLLM` subclass crashed on the async streaming path (streaming with no tools bound; with tools the call routes through the sync path and was unaffected). It is now a coroutine returning an async iterator, matching `Model`. `MockLLM` additionally gains its own `adispatch_streaming`, since it streams from configured outputs rather than through `model_call_with_stream` and would otherwise raise `NotImplementedError`.
