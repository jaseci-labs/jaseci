- **Fix: Host client build runs on the bundle's staged sources**: A scale deploy now builds the client bundle inside the same filtered staging copy that defines the `.jab`'s membership, so files the bundle strips (`.env`, the raw `jac.toml`, `.jacignore`-parked trees, key material) no longer reach the shipped dist. A build that references a file outside membership fails loud on the host, naming the file, the matching `.jacignore` pattern, and the fix. A `.env` that declares `VITE_`-prefixed values is called out by key before the build, since those now compile to `undefined` in the served JS (put public build-time values under `[client.vite.define]`), and a `[scale.microservices.client] entry` that names a missing file fails the deploy instead of silently shipping a gateway with nothing to serve. The built dist replaces `<project>/.jac/client/dist` in one directory swap rather than being rebuilt in place, and a `jac.toml` the loader rejects fails the deploy instead of silently skipping the client build. An explicit `entry = false` now disables the client build even when the project has client source, instead of being overridden by the `main.jac` guess. The membership diagnosis names the first three excluded files and then says how many more it withheld, so an operator who fixes what it named does not redeploy into the same error with the next three.
