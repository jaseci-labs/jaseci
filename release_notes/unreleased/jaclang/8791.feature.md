- **The OSP kernel is rewritten in idiomatic Jac, and the drifted edge/walk semantics move back into it (#8775)**: the portable kernel's hand-rolled open-addressed int tables, parallel row arrays and `[0]` integer cells become `OspGraph`/`EdgeRow`/`Adj` objects over dicts and sets, and the walk half becomes an `OspEngine` whose resumable `next_slot` state machine both the sync engine and the sv async driver share (the copied async twin loop is deleted). The kernel now owns the type/descriptor registries and the hop semantics every backend had re-implemented: edge-type filters are subtype-aware on all backends (`[->:Base:->]` no longer misses `Sub` edges on cl/na), predicate hops, chains, broadcast connect and the pred/list disconnect forms are single kernel entry points (native's per-callsite inline IR loops and ES's O(deg²) intersection are gone), and multi-origin edge-predicate dedup is global everywhere. Host gaps closed along the way: cl lowers `visit ... else`, stops running code after `disengage`, applies `+>:E: x=1 :+>` connect assignments, and gives bare `++>` a tagged `GenericEdge` object; the py backend surfaces OSP tag collisions at compile time (new E5102) and the sv runtime refuses them loudly at first use; native reads `WalkScope` layout from the symtab only and reports a kernel unit that fails to compile or link (E5025) instead of swallowing it. The kernel additionally gains a light adjacency API with a `one_sided` connect flag; on the server the light tier stays anchor-resident (weakref-backed, GC-reclaimable) -- moving it into the process-global kernel pinned every transient graph for the life of the process, which blew worker RSS during the payload precompile. That investigation also fixed a latent `WorkPool` bug: a retired worker's pipe fds were never reaped, so each retire leaked two descriptors until a long build pushed pipe fds past `select()`'s 1024 limit.
