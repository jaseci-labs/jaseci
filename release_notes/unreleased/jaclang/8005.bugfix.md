- **Fix: Closure-typed ternary results are wrapped, not reinterpreted**: the pointer fast path added with the ternary union rule short-circuited to a raw bitcast before `_coerce_type_inner`'s closure-wrapping branch, so `f = make_adder(10) if flag > 0 else quad` reinterpreted the bare function pointer as a `{fn, env}` closure struct and segfaulted on the call. The fast path is gone and the coercion routes through `_coerce_type`, which already bitcasts pointer to pointer, wraps a bare function into the closure layout, and re-marks the result owned.
- **Fix: Declared multi-member unions no longer crash the native pass in global position**: `_codegen_const_expr` built a scalar LLVM constant regardless of the target type, so a `glob x: int | str = 11` whose slot now lowers to a tagged `jacval` raised `'int' object is not iterable`. Non-scalar targets are declined and the existing runtime glob-init path does the store.
- **Fix: Boxed operands in native arithmetic diagnose instead of crashing**: arithmetic on a tagged value (`v + 1` where `v: any`, and now also a declared `int | str` parameter) raised an internal `AttributeError` out of `_emit_binary_op`'s integer tail. It reports E5092 instead, so the module demotes to the server backend like every other unlowerable shape. Dynamic arithmetic on boxed values remains unimplemented.
