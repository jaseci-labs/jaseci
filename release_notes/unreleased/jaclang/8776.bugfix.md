- **`del` means the same thing under all three backends**: the client backend used to drop `del d["k"]`, `del o.x` and `del node` on the floor and disconnect edges instead of destroying them, and the native backend deleted the wrong element for `del L[i:j]` and silently ignored `del o.x` without a deleter. Both now lower every form per the one rule, with E5092 and a message for the two shapes native cannot lower yet. `PyastBuildPass.proc_delete` kept only the first target of a multi-target Python `del`; fixed. Malformed targets report E0083 with the target's own span instead of E5043 from bytecode generation.
