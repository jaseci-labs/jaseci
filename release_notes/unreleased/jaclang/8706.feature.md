- **`jac test` absorbs the coverage that lived only in CI workflow YAML**: `[test] directories` accepts a list of discovery roots, so the in-package suites (compiler equivalence, byllm, scale) join the standard plan instead of existing only as ci.yml invocations. `[test] isolate` globs give a file a dedicated worker process and `[test] serial` globs run files one at a time after the parallel phase, replacing the shell loops CI used for the scale suite. A test module whose import fails on a missing optional dependency now reports as a named skip, and `JAC_TEST_STRICT=1` turns those skips into failures so a provisioned CI lane cannot lose coverage quietly; `jaclang.testing.requires` adds `require_module`/`require_tool` detection gates and `require_flag` opt-in gates. `JAC_LLVM_SHIM=none` disables the LLVM shim explicitly, making the no-native degradation path testable from the suite.
