- **Native: accessor (`{ getter; setter; }`) fields read a data slot nothing ever wrote**: a property has no instance storage -- Python's `property` is a class attribute, and Jac's own convention puts any backing store in a separately declared `has` (`_gen` behind `gen`, `_sym` behind `sym`) -- but the native backend gave one a data slot anyway and never emitted the accessor bodies at all. `nd.loc.orig_src` compiled to a load of the field's layout index, which on the sealed parser dereferences garbage and on an ordinary object returns a plausible, well-typed wrong value. An accessor-only `has` now contributes method slots (`<field>.__get__`, `.__set__`, `.__del__`) rather than a data slot, in the same central `LayoutRegistry` every unit reads, so the struct body, the exported marshalling layout and the rc trace functions move together; `impl Cls.field.getter` bodies lower like any method, including from an impl annex and for archetypes imported from another unit; and reads, writes and `del` route through the accessor, virtually where the class dispatches virtually, so an overridden property answers on the runtime class. A bare `getter;` names no signature, so the field's declared type stands in for the result and for a setter's implicit `value`, matching what the bytecode backend emits for the same declaration. Sealing the parser now surfaces 24 properties in `unitree` whose bodies are Python-only or hit a known backend gap -- they were invisible before because nothing lowered them -- each enumerated with its cause in `test_unitree_seal_census.jac`, and each shown unreachable from the sealed entry points by `test_sealed_seam_reachability.jac` rather than assumed so. Sealed-parser parity is still blocked, now on a single named defect (#8086): a field access through a reference typed as a non-primary base uses that base's slot offsets, so `AstSymbolNode._init_symbol` writes `self.name_spec.name_of` at `NameAtom`'s offset inside a `Name`. That write previously landed in one of the dead accessor slots this change removes, which is why it was survivable.
