- **Scale: the admin Runtime card reports the Jac version**: the Metrics page's "Runtime" card showed the Python version, taken from the `python_info` metric that `prometheus_client` registers for free, which is an implementation detail rather than the number an operator needs when checking whether a deployment matches its `project.jac_version` pin. The Prometheus collector now registers a `jac_info` gauge carrying a `version` label resolved inside the serving process, and the card reports `Jac <version>` instead. Because `jac_info` follows the standard Prometheus build-info idiom, a real scrape can also alert on version skew across services.
