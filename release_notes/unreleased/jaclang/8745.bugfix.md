- **Object-Spatial: building and traversing an in-memory graph no longer pays for persistence**: A graph of `node`s that is never connected to a root and never reaches a store is an ordinary in-memory data structure, and it now costs what its topology costs. Connecting was quadratic -- the graph kernel's node table hashed its keys in a way that sent sixteen consecutive handles to one bucket, so inserting the nth edge walked about half the table (a 2,000-edge chain cost 85us per connect, 8,000 edges cost 488us, and 100,000 edges did not finish in five minutes) -- and detaching had the same shape, because an edge's row was found by scanning every row ever allocated. Both are flat now. Each edge also minted three `uuid4()`s and three `Permission` objects and keyed its registries by `str(id)`, which is machinery only a store needs: a transient anchor now carries no id and no permissions until something persists it, cutting an edge from ~2.2 KB to a few hundred bytes. Traversal (`[-->]` and friends) no longer routes a rootless, storeless graph through the persistence query planner, its UUID round trip and its access-control checks. Persisted graphs are unaffected: the identity appears the moment persistence needs it and survives the round trip.
