- **Fix: a broken client build now fails the deploy immediately instead of shipping and letting the gateway pod retry at boot**: the host-side bundle build swallowed every failure ("the gateway pod will build it on boot instead") and the deploy continued with a partial or absent client dist - the failure then surfaced minutes later as gateway crash-loop noise, or as a healthy-looking deploy serving a 404 client. The deploy now aborts with the build's actual output when `jac build --client web` fails or emits no `dist/index.html`, and the pod entrypoint's rebuild fallback is removed: the gateway serves exactly the bundle built at deploy time. Headless apps and dry runs are unchanged.
