- **Runtime: field writes are gated at the assignment, under the acting principal**: A permission-denied field write used to land on the shared in-process anchor and only be skipped at flush time, so the next flush performed by any principal holding write access committed the unauthorized value. The write hook installed by `track_writes` now consults `check_write_access` before it mutates: a denied assignment records the `PermissionDenied` diagnostic (raises `PermissionError` under `JAC_STRICT_PERMISSIONS`) and never mutates the shared object, matching how edge creation and delete are already gated at the operation. Because the hook is only installed once an anchor becomes persistent, a transient archetype pays nothing. The denial hint now names the scoped `Jac.allow_root(node, root_id, AccessLevel.X)` alongside the deployment-global `grant(node, ...)`. Fixes #8346.
