- **Auth (breaking): the scale server now 401s on a present-but-rejected token, including on public walkers**: On every `jac-scale`-served endpoint, an `Authorization: Bearer` credential that fails validation (expired, revoked, or malformed) now returns `401 Unauthorized` instead of being silently downgraded to the guest identity. This applies to **all walkers and functions, public (anonymous-allowed) endpoints included**: a browser holding an expired session that previously got served as guest on a public endpoint will now get a 401. Requests with *no* Authorization header are unchanged and continue to be treated as anonymous/guest on public endpoints; only authenticated walkers still require a valid token. Scale operators whose clients rely on stale credentials silently falling back to guest must clear the stale session client-side or refresh it. The same rejection applies to any transport adapter that pre-validates identity (`identity_prevalidated`, e.g. JWT middleware) and supplies a token that resolves to no user.
