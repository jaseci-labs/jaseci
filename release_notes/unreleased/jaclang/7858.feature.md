- **Feature: Ownership contract positions lower to LLVM parameter attributes**: on the native pathway, heap-typed parameters annotated `own` or `&mut` are stamped `noalias`, `&` is stamped `noalias readonly`, and `imm` is stamped `readonly`, handing the checker's exclusivity and immutability facts to the optimizer (load hoisting, vectorization) with zero semantic change; unannotated parameters are untouched.
- **Feature: Nested scalar lists under zero-RC enforcement**: fresh inner list literals (`[[1, 2], [3]]`, `grid.append([4, 5])`) now move into outer lists in nogc-enforced modules, with the outer element-drop slot stamped to the inner container's drop so inner buffers free exactly once at outer drop, byte-identically across gc modes. The fix also corrects a latent gc-none move bug: elements appended by list-literal construction are moves, so the construction no longer emits an immediate release of the just-appended element. Deeper nesting, named inner bindings, and non-scalar inner elements stay fenced (E1406).
- **Feature: Owned lists of archetype elements under zero-RC enforcement**: fresh constructor results now move into `append`/`insert` and list literals inside nogc-enforced modules (`xs.append(Res(tag=i))`), the container stamps the element type's drop in its per-instance element-drop slot, and each element is freed exactly once at container drop -- byte-identically under every gc mode. Named archetype bindings, sets, dict keys/values of archetypes, and nested containers stay fenced (E1406).
- **Feature: Inline flattening of own-typed fields under headerless codegen**: in `--enforce-nogc --gc none` modules, an own-typed field of a concrete, acyclic, non-OSP archetype embeds by value in the parent's LLVM struct -- no pointer slot and no separate allocation; stores copy the payload in and free the source shell, reads yield the interior address, and the parent's drop tears the field down in place. Managed modes keep pointer fields, with byte-identical program output across all three gc modes.
- **Feature: Own-typed fields keep values in the owned world**: storing an owned value into a field declared `has ref: own T` is now a move within the owned world rather than an E1402 membrane seal under nogc enforcement -- the source binding is still consumed, the parent frees the field at its own drop point, and an overwrite drops the old value first, at identical program points under every gc mode. Stores into unannotated fields, subscripts, graph objects, and `glob` state seal exactly as before.
- **Feature: Owned locals with frame-local borrows are stack-promoted**: an `own` local whose call-position uses are checked borrows (`&`/`&mut` arguments to borrow-annotated parameters that cannot passthrough-return them) or scalar field reads now allocates on the stack instead of the heap, under every gc mode, with identical drop points; `JAC_RC_STATS=1` reports the count as `promoted=N`. Unannotated locals keep the previous conservative analysis.
- **Feature: Borrows split at single-field granularity**: a borrow taken as exactly one attribute level on a root name (`&p.name`, `&mut p.left`) records the field it covers, so borrows and writes touching provably disjoint fields of one owner now coexist instead of tripping E1302/E1303. Whole-object borrows, same-field overlaps, subscripts, and paths deeper than one level conflict exactly as before, and a field borrow still pins its whole owner for destruction (E1304), escape (E1306), and sendability (E1308) checks.
