- **Feature: Ownership contract positions lower to LLVM parameter attributes**: on the native pathway, heap-typed parameters annotated `own` or `&mut` are stamped `noalias`, `&` is stamped `noalias readonly`, and `imm` is stamped `readonly`, handing the checker's exclusivity and immutability facts to the optimizer (load hoisting, vectorization) with zero semantic change; unannotated parameters are untouched.
- **Feature: Droppless affine inference for unannotated locals**: a plain local whose object never escapes -- scalar field reads under calls and returns included -- now stack-allocates in managed modes with zero user action, reported via the `promoted=` rc-stats counter. Types with a `drop` hook are excluded by the codegen gate, so destructor timing never changes; output is byte-identical across gc modes.
- **Feature: The `imm` prefix operator (freeze)**: `d = imm a;` promotes a statically unique value (an `own` binding, consumed, or a fresh expression) into the deep-immutable world, and the binding infers `imm` from the operator. Uniqueness is checked by the ownership pass (new `E1311` when it cannot be proven), which is what lets the operator erase to its operand on every backend -- no builtin function, no name resolution, no divergence between gc modes. The surface rule this completes: states are annotations, transitions are operators (`&x`, `&mut x`, `own x`, `imm x`), and the exit is a call (`managed(x)`).
- **Feature: Reference-yielding loops**: `for x in &xs` iterates shared per-element borrows and `for m in &mut xs` exclusive ones, lowered as index loops with no reified iterator object -- the loop is the borrow's extent, checked by the ownership pass (escaping the loop variable is E1306). Fixes a gc-none divergence where the loop variable's element was dropped by the frame-release machinery (an alias, not an owner): ref-loop mutation is now visible after the loop byte-identically under every gc mode.
- **Feature: ownbench `own_aos` kernel**: a Phase B owned-heap kernel (archetype element lists + an inline-flattened `own` field) joins the differential suite -- one source, three gc modes, byte-identical digests, `--assert-no-rc` on the enforced build, and an exact `erase.jac` round-trip.
- **Feature: Nested scalar lists under zero-RC enforcement**: fresh inner list literals (`[[1, 2], [3]]`, `grid.append([4, 5])`) now move into outer lists in nogc-enforced modules, with the outer element-drop slot stamped to the inner container's drop so inner buffers free exactly once at outer drop, byte-identically across gc modes. The fix also corrects a latent gc-none move bug: elements appended by list-literal construction are moves, so the construction no longer emits an immediate release of the just-appended element. Deeper nesting, named inner bindings, and non-scalar inner elements stay fenced (E1406).
- **Feature: Owned lists of archetype elements under zero-RC enforcement**: fresh constructor results now move into `append`/`insert` and list literals inside nogc-enforced modules (`xs.append(Res(tag=i))`), the container stamps the element type's drop in its per-instance element-drop slot, and each element is freed exactly once at container drop -- byte-identically under every gc mode. Named archetype bindings, sets, dict keys/values of archetypes, and nested containers stay fenced (E1406).
- **Feature: Inline flattening of own-typed fields under headerless codegen**: in `--enforce-nogc --gc none` modules, an own-typed field of a concrete, acyclic, non-OSP archetype embeds by value in the parent's LLVM struct -- no pointer slot and no separate allocation; stores copy the payload in and free the source shell, reads yield the interior address, and the parent's drop tears the field down in place. Managed modes keep pointer fields, with byte-identical program output across all three gc modes.
- **Feature: Own-typed fields keep values in the owned world**: storing an owned value into a field declared `has ref: own T` is now a move within the owned world rather than an E1402 membrane seal under nogc enforcement -- the source binding is still consumed, the parent frees the field at its own drop point, and an overwrite drops the old value first, at identical program points under every gc mode. Stores into unannotated fields, subscripts, graph objects, and `glob` state seal exactly as before.
- **Feature: Owned locals with frame-local borrows are stack-promoted**: an `own` local whose call-position uses are checked borrows (`&`/`&mut` arguments to borrow-annotated parameters that cannot passthrough-return them) or scalar field reads now allocates on the stack instead of the heap, under every gc mode, with identical drop points; `JAC_RC_STATS=1` reports the count as `promoted=N`. Unannotated locals keep the previous conservative analysis.
- **Feature: Borrows split at single-field granularity**: a borrow taken as exactly one attribute level on a root name (`&p.name`, `&mut p.left`) records the field it covers, so borrows and writes touching provably disjoint fields of one owner now coexist instead of tripping E1302/E1303. Whole-object borrows, same-field overlaps, subscripts, and paths deeper than one level conflict exactly as before, and a field borrow still pins its whole owner for destruction (E1304), escape (E1306), and sendability (E1308) checks.
- **Feature: Loud seals (W1312)**: passing an owned binding to a resolved callee's unannotated parameter -- the membrane acting silently, consuming the caller's binding at a distance -- now warns, pointing at `managed(x)` for an explicit seal or an `own` parameter for an intentional transfer. Explicitly wrapped and own-parameter calls stay quiet.
- **Feature: Scoped lending across `flow`**: an inline `&`/`&mut` of an owner may now cross a flow boundary when its handle is bound and `wait`-ed in the same block before any other use of the owner -- the join is the borrow's extent, so parallel readers borrow local data with no move, no copy, and no annotation naming the extent. Unjoined lends and owners touched between spawn and join stay E1308.
- **Feature: Frozen regions**: `fr = imm r` on an owned `Region` handle consumes it and transfers handle-ness -- the `imm Region` result deep-freezes the subgraph and crosses `flow` freely under the existing imm sendability rule, so one frozen graph can be shared with any number of parallel readers. Opening a frozen handle for allocation is E1309, and reopening the consumed source handle is E1301.
- **Feature: Affine walkers**: a walker bound `own` is use-once computation -- `spawn` moves it into the traversal, so a second spawn of the same binding is E1301 and double-accumulation bugs become compile errors. Unannotated walkers keep managed reuse semantics unchanged.
- **Feature: Ownership states in Callable positions**: higher-order signatures may declare ownership states on callable parameters (`Callable[[own Buffer], None]`); the states parse, check, and compose with the ordinary consumption rules, pinned by a fixture. The views-and-zero-copy design direction and its representation fence are now documented in the ownership reference.
- **Feature: Abort-with-drops in enforced modules**: an unhandled `raise` in a nogc-enforced frame now runs that frame's statically-known drop obligations -- the same cleanup block scope-exit uses, with already-dropped locals nulled so each drop fires exactly once -- before printing the abort banner and terminating. Deterministic resource cleanup with zero exception-table machinery.
- **Feature: Element-space loans**: reference-yielding loop variables now record a loan on the container's element space, so growing or shrinking the iterated container inside the loop (`append`/`insert`/`remove`/`pop`/`clear`/...) is a compile error (E1303 shared, E1302 exclusive) -- the iterator-invalidation bug class removed at check time. The loop statement is the loan's extent, structurally; grows after the loop stay clean.
- **Feature: Inferred move-in for container arguments**: a named binding appended into a container while provably dead-after (single non-definition use, outside any loop) now moves in instead of copying under gc-none -- the string duplication disappears and the source slot is nulled so its release is a no-op. Bindings still live after the append keep copy-in semantics; output is byte-identical across gc modes.
- **Feature: Regions inside zero-RC enforced modules**: `in <handle> { }` opens are no longer E1406-fenced under `--enforce-nogc` -- the arena core (bump allocation, dtor log, bulk free) needs no reference counting, so build-traverse-discard region code now compiles headerless with `--assert-no-rc` passing. Region allocations inside opens route to the arena (never the plain-malloc path), region-rooted locals are shielded from per-iteration, overwrite, and scope releases (the arena's dtor log owns their teardown), and drops fire in the same LIFO order as the managed modes, byte-identically.
- **Feature: Inferred anonymous regions for unrooted spawns**: a code block that builds a graph from fresh node locals, connects them only among themselves, and consumes it with expression-statement spawns is proven unrooted by a conservative may-reach-root scan and anchored to an implicit anonymous region -- arena allocation for the nodes, edges, and inline walker, `drop` hooks LIFO right after the last spawn, one bulk free, byte-identical across gc modes. Any contact with `root`/`here`, an escaping member, a consumed spawn result, or control flow through the extent declines the inference and the graph stays managed. The ephemeral-OSP fast path at zero annotation, native backend only.
- **Feature: Connect-as-seal**: attaching region topology to a managed node stops being a flat E1307 rejection and becomes the membrane seal for subgraphs -- a directed connect from a managed anchor into a region-local node, under an open on an owned named handle, consumes the handle (E1301 on reuse, via the same operator-move dataflow as `imm` and spawn) and promotes the topology into the managed world: pages stay live, teardown never runs, drop hooks stay silent, and the subgraph traverses from the anchor after the open closes, byte-identically across gc modes. The seal closes the region for graph operations, and every non-seal shape (region edge out to managed, undirected wiring, anonymous opens, borrowed `&Region` handles) keeps E1307.
- **Feature: Sub-arena `partition()` + reabsorb**: `r.partition()` on an owned `Region` handle yields an owned child handle -- a full region (openable, allocatable, sendable across `flow` as a moved own) whose death reabsorbs its memory and drop log into the parent. Hooks fire exactly once, at the parent's death, child entries first; a parent dying before its children zombie-defers its entire teardown to the last reabsorb, so no code shape frees pages a child still draws on. Ownership of the children is the isolation proof for data-parallel building over disjoint subgraphs; the per-child bump-pointer page sharing remains regions-lane allocator work behind this contract. Works identically on the Python backend (children hand their drop lists to the parent).
- **Testing: string-representation oracle kernel**: `own_strops` joins ownbench -- the full native string surface (concat, slices, f-strings, the method set, membership, comparison, `dict[str]` keys, int round-trip, string borrows) under ownership annotations, byte-identical across all three gc modes with the enforced build passing `--assert-no-rc`. This is the migration oracle any change to the string representation (fat descriptors, zero-copy views) must keep green.
- **Feature: `flow for` -- the disjoint-partition loop**: the existing `flow` modifier applied to the existing loop (no new keyword). `flow for x in &xs { }` is a parallel read-only map; `flow for m in &mut xs { }` fans out disjoint exclusive element lends; the closing brace is the implicit join. The checker enforces the shape: the collection must be lent (E1313 otherwise), control flow may not cross the join (E1313 on `break`/`return`/`yield`/`disengage`; `continue` is fine), nesting is rejected for now, and body captures follow the sendability rule (E1308 on shared mutation or non-sendable reads -- write through the `&mut` element instead). Both backends currently lower it to the same degenerate sequential execution as native `flow` calls, so erasure is byte-exact by construction; parallel execution rides the shared concurrency runtime with these semantics already pinned. The reduction idiom and the chunked form (`&mut xs.chunks(n)`, gated on container views) are named follow-ups.
- **Fix: scoped lending rejects side exits before the join**: `h = flow f(&a); ... wait h;` now also requires that no `return`/`raise`/`break`/`continue`/`yield` sits between the spawn and the join unless the join is on that exit path itself (`return wait h;` stays legal) -- an early return used to slip past the linear scan and leave the task borrowing `a` across the frame exit.
- **Feature: parallel `flow for` in zero-RC enforced builds**: under `--enforce-nogc --gc none`, `flow for` now runs genuinely parallel -- the body is outlined into a range function, element chunks fan out over pthreads, and the closing brace joins (`JAC_FLOW_THREADS` sets the width, default 4; failed spawns fall back inline). The placement is the thesis made executable: an `--assert-no-rc` binary provably contains no refcount operations and no shared runtime kernel, and the checker bans every unsound body capture, so threads are unconditionally safe -- parallelism arrives exactly where machinery absence is proven. Measured ~6x on 8 threads for an element-map kernel; post-join state is byte-identical across thread counts and gc modes (managed modes and Python keep sequential execution until atomic-RC crossing lands).
