- **Fix: Native ternaries whose branches lower differently**: `a if cond else b` now unifies its two branch representations through the same rule declared multi-member unions use (shared lowering wins, an all-pointer pair keeps the first member's layout, a genuinely mixed pair boxes to `jacval`), instead of building a phi whose incoming values had different LLVM types and failing the whole module. Branches that already shared a lowering are unchanged and never box.
- **Change: Declared multi-member unions lower by representation, not by first member**: the same PR replaced `_lower_type`'s member-zero lowering for declared unions with lower-all-and-unify, so `int | str`, `int | float` or `bool | str` now lowers to a tagged `jacval` where it previously took the first member's scalar type and silently reinterpreted the others through that layout. This reaches every position `_lower_type` feeds: function parameters and returns, and module globals. It needs no `NATIVE_ABI_VERSION` bump (that constant versions the schema of the sealed layout descriptor, which is unchanged) and stale artifacts are already invalidated per release by the `jaclang` version mixed into the module cache key. Single-representation and all-pointer unions lower exactly as before.
