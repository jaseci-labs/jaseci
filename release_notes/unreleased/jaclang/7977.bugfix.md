- **Fix: Native ternaries whose branches lower differently**: `a if cond else b` now unifies its two branch representations through the same rule declared multi-member unions use (shared lowering wins, an all-pointer pair keeps the first member's layout, a genuinely mixed pair boxes to `jacval`), instead of building a phi whose incoming values had different LLVM types and failing the whole module. Branches that already shared a lowering are unchanged and never box.
