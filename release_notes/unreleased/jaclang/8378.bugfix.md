- **CLI: bool flags only offer `--no-X` where negation is meaningful**: the parser auto-generated a `--no-X` twin for every bool flag, but on a default-off flag `--no-X` parsed to the same value as not passing the flag at all, so help advertised options like `jac install --no-npm` (#7464) that could never do anything. Flags that default to on (`jac run --no-main`, `jac run --no-cache`) keep their working negations, now rendered as one paired entry; default-off flags no longer advertise or accept a fake `--no-X`, and the nonsensical `--no-no-save` style twins disappear from help and completions. Skipping npm during a full install remains available via `JAC_CLIENT_SKIP_NPM_INSTALL`. The ninja editor's check integration drops its no-op `--no-nowarn` argument.
