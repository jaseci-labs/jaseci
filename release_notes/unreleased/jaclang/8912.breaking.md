- **Production serving is one assembly, and `jac start --workers N` exists**: the core and scale server stacks collapse into a single `JacAPIServer` on the Jac-native transport, with the scale features (SSO, webhooks, websockets, the jobs API, the admin portal, events, metrics) registered as extensions rather than a second class tree. The transport gains what uvicorn used to provide and more: a pre-fork supervisor (`[serve.workers] count`, `--workers`, `auto` from the cgroup CPU quota) with worker restart, recycling (`max_requests`), hung-worker detection and SIGHUP rolling restart; SIGTERM drain with a readiness probe that flips to 503; TLS on the listener; trusted-proxy resolution of `X-Forwarded-*`; request-line, header, body and connection limits with the right status codes; timeouts on every read and an optional per-request budget; strict HTTP framing; gzip negotiation; `Date`, `Server` and `X-Request-Id` headers; a sized sync-handler thread pool; WebSocket keepalive pings; ETag, Last-Modified and Range on static files; spooled multipart uploads; and an access log with latency, bytes and request id in text or JSON. Everything is configured under `[serve]` with `JAC_SERVE_*` environment mirrors, which the Kubernetes target now sets on every pod. Identity is Postgres-backed JWT everywhere (the SQLite core store and `[serve] identity` are gone; existing SQLite accounts do not migrate), `[scale.jwt]` moves to `[serve.auth]` and a cluster refuses to sign with the shipped placeholder secret (`jac scale deploy` mints one into the app Secret). Static `@schedule` tasks take a database lease so a fleet fires them once, the gateway rate limiter keeps its buckets in the shared state backend, and the memory WebSocket backplane, `--dev`, and database-less events are refused under more than one worker rather than degraded. Fixes #8912; also closes #8903, #8865, #8859, #8855, #8854, #8851, #8852, #8333.
