- **The jaclang tree reorganizes by function, and the old import paths are gone** (#8681, #8682): `jac0core/` dissolves into `compiler/` (`frontend/`, `driver/`, `passes/`, `types/`, `backends/{py,es,native}/`, `placement/`, `tools/`), `runtime/`, and `lib/`; `runtimelib/` dissolves into `client/`, `server/`, `data/`, `testing/`, `runtime/`, and `dist/`; `utils/`, `payload/`, and `publish/` become `dist/` (plus `compiler/tools/`); `langserve/` becomes `lsp/server/` beside `lsp/protocol/`. Which files the jac0 seed transpiler compiles is now declared in `jaclang/bootstrap_manifest.py` and gated in CI (`scripts/check_seed_manifest.py`), so tier membership no longer follows directory placement. This is a clean break: `jaclang.jac0core.*` (beyond the frozen boot seam), `jaclang.runtimelib.*` (including the deprecated `jaclang.runtimelib.runtime` alias), `jaclang.utils.*`, and `jaclang.langserve.*` import paths no longer exist -- for example `jaclang.runtimelib.test` is now `jaclang.testing.test` and `jaclang.jac0core.jaclib` is `jaclang.lib.jaclib`. Alongside the moves: the 1,290-line `compiler.jac` driver file is dissolved into named modules (`pass_driver`, `schedules`, `source_failures`, `boundary_classify`, `na_coverage`, with `patch_co_filenames_bytes` in `jir`), the hidden `internal_program` redirect is now the `SelfHostCache` owned by `JacRuntime` (one self-host program per process; tests and fixtures under the jaclang tree compile into the caller's program without `force_target_program`), `JacLangServer` composes a `JacProgram` at `.program` instead of inheriting one, and the basename collisions are renamed (`server/auth_types`, `server/task_scheduler`, `testing/testkit`, `client/client_react_core`). `jac0core/` remains only as the launcher boot seam (`sealed`/`cache_paths`/`ext_registry`/`cli_boot`) because built binaries bake those paths into their boot sources.
