- **Interop manifest as single source of truth**: every cross-codespace route now flows through `BoundaryAnalysisPass` and typed `InteropBinding`s. Bridged plain client imports of server `def:pub` functions are recorded as cl->sv bindings, all native bindings carry real signatures (including posonly/kwonly params), and client-side sv stubs are generated from the recorded binding instead of re-deriving from the AST. New `E5093` rejects param/return types that cannot cross the native/Python ctypes boundary instead of producing garbage through the silent `c_int64` default. Endpoint effect classification moved to a dedicated `EndpointEffectPass`, dead model fields (`route`, `is_direct`, `is_composed`, the unused manifest ctypes table) are removed, and server endpoint mounting uses a single first-wins merge policy with a logged conflict warning.
