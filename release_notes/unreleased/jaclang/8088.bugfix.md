- **Native: a method's receiver is a borrow, so `return self` now hands back a reference of its own**: `self` was bound as a plain named local and left out of `param_vars`, the set that marks the slots a frame does not own. Every emitter site that decides "this named local owns its value, so returning it moves that reference out" therefore said yes for the receiver, which owns nothing: `return self` (and `return (self, ...)`, which the return-tuple path treats the same way) skipped its retain and handed the caller a borrow where the calling convention promises +1. The caller's release of that "owned" result then dropped a reference nobody had taken. It reads as a container bug because a container is where it lands: `self.kid = [x.set_parent(self) for x in self.kid]` in `UniNode.postinit` retains each element into the new list and releases the call result, which nets zero when the call returned a borrow, so the rebuilt list held nodes it did not own and they were freed at the parse function's scope exit -- use-after-free reads whose victim moved with the heap layout. The receiver now joins `param_vars` at every binding site (plain methods, signature-less methods, event abilities), which is where the walker's `here`/`visitor` receiver already sat, and the two move-out sites retain like they do for any other parameter. In the parser's `JAC_RC_DEBUG_CODEGEN` ledger the same `Token` that used to reach `RC DOUBLE-FREE` at the end of its parse now settles at the count the tree implies.
- **Native: set and dict comprehension elements of archetype type get a pointer slot**: both comprehensions picked their element storage class off the *syntax* of the element expression -- a constructor call, a tuple, a field read -- and fell back to a raw `i64` for anything else, including a method call and the loop variable itself. A raw slot takes no reference, so `{x.self_ref(owner) for x in src}` and `{x.tag: x.self_ref(owner) for x in src}` stored their elements as bare integers and every element died with the source list. Both now widen to a pointer slot whenever the element expression's static type is an archetype, matching the list comprehension, which already consults the static element type first.
