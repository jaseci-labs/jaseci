- **Test runner: a config pin set during one test no longer decides what later tests compile under**: an explicit `set_config` pin wins over file-anchored config resolution for every path in the process, and the test pool's long-lived fork workers carried a leaked pin across tests and files. One leaked repo-root pin was enough to put `no-print` in force for a dynamic module synthesized under `/tmp`, failing `dynamic archetype creation` in a full-suite run even though the file passes alone. `_fresh_jac_state` now captures the run's pin state on first use and restores it before every test, alongside the runtime slots it already resets.
