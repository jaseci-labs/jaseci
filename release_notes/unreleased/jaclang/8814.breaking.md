- **Breaking: One cache root, two env vars**: All of jac's caches now live under a single platform root (Linux `~/.cache/jac`, macOS `~/Library/Caches/jac`, Windows `%LOCALAPPDATA%\jac\cache`) with per-store directories (`modules/`, `bootstrap/`, `kernels/`, `stubs/`, `runtimes/`, `apps/`, `bin/`, `models/`, `browser/`, `pg/`). `JAC_CACHE_DIR` relocates the whole root and `JAC_DATA_DIR` the durable data root; the per-store variables `JAC_CACHE_HOME`, `JAC_SCALE_CACHE_DIR`, `JAC_MODELS_DIR`, and `JACBROWSER_CACHE` are removed. Old cache content is orphaned and regenerates on demand.
- **Breaking: Embedded Postgres cluster moved to the data root**: The shared cluster now lives at `~/.local/share/jac/pg/main` (`JAC_DATA_DIR` honored) instead of under the cache, so purging caches can never touch data. An existing cluster is not migrated: copy `~/.cache/jac/pg/main` across once, or point `JAC_DATA_DIR` at the old location.
- **Breaking: `jac run --no-cache` bypasses cache reads**: The flag now forces a rebuild for the run (equivalent to `JAC_REBUILD=1` plus `JAC_NO_PRECOMPILE=1`) instead of deleting `.jac/cache` directories below the target file. `jac nacompile --scrub` still scrubs project caches.
- **Breaking: `[cache] enabled` removed from jac.toml**: The key was parsed but read by nothing; `[cache] dir` remains. Stale keys in existing tomls are ignored.
- **Breaking: Loose-file compiles cache globally**: Compiling a `.jac` file outside a project uses the global `modules/` store instead of creating a `.jac/cache` directory next to the source. Project-local caching is unchanged.
