- **Fix: subscripting a class runs its metaclass `__getitem__`**: looking an enum member up by name (`Tokens["A"]`) was read as a generic specialization and rejected with `Cannot assign Tokens[Literal["A"]] to Tokens`, and the false error also kept the module off the native pathway. A class subscript now consults the metaclass first, the way Python does, so enum lookup by name types as the enum member and any class whose metaclass defines `__getitem__` is usable. A metaclass method's `self` also binds the class it was reached through, so the result is the specific enum rather than the base `Enum`. Classes with no metaclass `__getitem__` specialize generics exactly as before.
