- **`[scale.database] indexes` now actually indexes**: Index promotion built a generated column and an index that no query ever referenced, so every predicate in every traversal stayed a scan. Two defects: `_pred_cond` emitted the raw `props->'archetype'->'<field>'` path and Postgres does not substitute a generated column for its own defining expression; and the column was `text` under a partial `WHERE arch_type = '<Arch>'` predicate, which sorts numbers lexically and cannot be matched against the subtype-aware `arch_type` test the compiler emits. The promoted column is now `jsonb` over `props->'archetype'->'<field>'` -- the same type and expression the compiler already compares against -- indexed without a predicate so subtypes are covered, and `compile_query` names the column whenever one is declared. Existing `text` promotion columns are rebuilt in place on the next `ensure_schema`.
