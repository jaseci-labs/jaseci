- **byLLM: usage and cost now reported for every invocation shape**: previously only surfaced for `stream=True, logging=True`; plain calls, non-logging streams, and tool-calling loops computed the same data and silently discarded it. All shapes now report consistently, and cache token fields are normalized across providers instead of being silently absent. See the docs for the full `tokens`/telemetry reference.
- **byLLM: minimum litellm version raised to 1.75.2**: required for accurate native cost on streaming calls; an older litellm still works, just without it.
