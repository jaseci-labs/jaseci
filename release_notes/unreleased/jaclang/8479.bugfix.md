- **byLLM: usage/cost now reaches every `by llm()` invocation shape**: previously only `stream=True, logging=True` calls surfaced token usage and cost; every other shape computed the same data and discarded it. All shapes now get the same visibility through the `tokens` field on `register_agent_callback`'s telemetry record, and the `usage` `StreamEvent` now always fires (with empty totals if nothing was measurable) instead of being silently skipped.
- **byLLM: minimum litellm version raised to 1.75.2**: needed for the native streaming cost byLLM now opts into (`include_cost_in_streaming_usage`) and for the tool-call rebuild's `logging_obj` handoff; an installed litellm below that still works, just without those two.
- **byLLM: `BaseLLM._usage_history` is gone**: usage now lives on the per-call `mt_run` instead. Anyone reading this private field directly gets a compile error rather than a silently empty list.
