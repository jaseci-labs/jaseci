- Jac gains `comptime`, compile-time metaprogramming as a fourth code context above the server/client/native split: `comptime { expr }` const-eval, `comptime if` with `target.has(...)`, and `comptime for` templates with `${...}` splices and interpolated names, expanded by a deterministic, fuel-bounded evaluator over the syntax arena immediately after parse so every downstream consumer sees only ordinary expanded syntax. Comptime code reflects over module declarations via `reflect.*` (source order, C3 constructor ordering) and builds spliced syntax only through `ct.name`/`ct.typ`/`ct.expr` fragments parsed by the real parser. The compiler eats its own dogfood: the entire arena surface -- 147 `mk_*` builders, kind ids, family tables, and materializer specs -- is now derived by comptime templates in `arena.jac`, replacing the `jac gen-unitree` generator and its 2,600 checked-in generated lines (the generator, `arena_schema.jac`, `arena_specs.jac`, and the builders annex are deleted); the jac0 bootstrap expands the same dialect at the text level, so the chain stays self-hosting with no derived text in the repo. The formatter formats templates unexpanded; the linter and checker analyze the expanded tree; comptime errors surface as `E0108` with template-site locations.
