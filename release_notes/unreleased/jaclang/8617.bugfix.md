- **Fix: optional-dependency fallbacks no longer fail `jac check`**: The `except ImportError` arms of the opentelemetry and pillow shims rebound an imported name by assignment (`IdGenerator = object;`, `PILImageCls = _PillowUnavailable;`), which the type checker reads as assigning to the imported declared type and rejects with E1001 whenever the real package resolves. Each fallback now declares a class of that name instead, matching the litellm shim.
