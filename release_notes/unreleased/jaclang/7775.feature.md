- **Implicit returns (Rust-style tail expressions)**: The final expression of a function, ability, impl, or lambda body written without a trailing `;` is now the return value -- `def add(a: int, b: int) -> int { a + b }`. The semicolon is the switch: `expr;` stays a discarded statement, a bare tail `expr` before `}` returns. The tail is type-checked exactly like an explicit `return` (`E1002`/`E1004`), and a semicolon-less expression anywhere other than a body's tail position is rejected with the new `E2084`. JSX components read especially well in the new form (`def:pub Badge(label: str) -> JsxElement { <span>{label}</span> }`); the bundled examples, templates, and the shadcn registry have been converted, and early guard returns stay explicit. Fully backward compatible -- the accepted form was previously a parse error.
