- **CLI: `jac ninja` and `jac ai` removed**: The fused neovim editor (`jac ninja`) and the built-in coding agent (`jac ai`) are gone, along with the editor tree and the agent's web UI. The `jac` binary no longer links neovim, so the build drops the neovim and Lua closure (and the `-Dno-ninja` option with it). Agent workflows continue through `jac mcp` plus the bundled guides (`jac guide`).
