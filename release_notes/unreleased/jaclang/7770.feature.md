The compiler now self-hosts its first stage on the native pathway in release
binaries: the seal AOT-compiles the hand-written lexer
(`jac0core/parser/lexer.jac` plus its `tokens.jac` closure) into a
per-platform shared library with a persisted marshal layout, recorded in the
sealed image's MANIFEST (format 4, `native_artifacts`, sha256 fail-closed).
At startup `parse()` binds `tokenize_full` through plain ctypes
(`jac0core/native_dylib.jac`) -- no LLVM, no MCJIT on the boot path -- and
token output is pinned byte-for-byte against the bytecode lexer, which
remains the transparent fallback for unsealed dev trees. Shared-library
emission moved to a reusable `shared_emit` module, and the Mach-O linker's
export trie is now a real compressed radix trie, fixing dlsym misses for any
export that is a strict prefix of another (e.g. `tokenize` /
`tokenize_full`).
