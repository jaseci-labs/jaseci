- **`jac test` shows progress and can list its plan** (#8682): test output
  now carries a pytest-style `[ NN%]` marker -- at each dot-line wrap, on
  every `--verbose` line, and on the final partial line -- computed as
  completed files over the discovery plan (a run stopped early by `-x` or
  `--maxfail` shows where it stopped). A new `--collect_only` flag (short
  `-c`) prints the discovered test files and a count without running
  anything, exactly the set a real invocation would execute. The plan can
  also be sliced: `--range N-M` runs only that percent window of the
  discovered files (either bound optional), and `--resume` (short `-r`)
  restarts from the file that failed last run -- each failing run records
  its earliest-in-plan failure in `.jac/test_state.json`, and a green run
  clears it, so `jac test -x` then fix, then `jac test -x --resume` is the
  whole loop.
