- **Fix: Escaping a keyword used as a name**: The error for a reserved word used as a name no longer suggests an escape that reads like a quoted pair. It now explains that the backtick is a prefix: one backtick before the keyword, with nothing after the name. Writing a closing backtick reports a single clear error instead of an unexpected-character error followed by a cascade of unrelated ones, and syntax errors show their help text again.
