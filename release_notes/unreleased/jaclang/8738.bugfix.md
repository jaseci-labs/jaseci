- **Fix: two checkouts sharing one `jac` binary no longer fight over the cache**: the editable dev loop picks a compiler source per process from the nearest `jac.toml`, but the module cache named its entries from the source path alone and only checked which compiler wrote them after opening the file. Two checkouts aimed at the same filename and each overwrote the other, so a warm cache never stayed warm. The compiler digest now names a generation directory under the cache root, so every tree keeps its own entries. Generations left untouched for 14 days are swept, along with the older flat layout; set `JAC_CACHE_GENERATION_TTL_DAYS` to tune the window or `0` to turn the sweep off.
- **Fix: kernel units can no longer be overwritten mid-compile**: the OSP and fmt kernel units were materialized at a fixed path per variant, so one process could replace the unit another was about to compile, and storing a derived artifact deleted the artifacts a different compiler had emitted for the same variant. Unit filenames now carry a digest of the sources they hold and are written once, which keeps each compiler's units and artifacts to itself.
