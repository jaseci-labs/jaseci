- **Type-checked compiles no longer rebuild builtin stubs per program**: the type system's eight stub modules (builtins, typing, types, enum, and the Jac ambient stubs) are now parsed once per process and shared across `JacProgram` instances, removing a ~1s constant from every first type-checked compile. Workloads that create many programs — `jac test`, `jac check` over many roots, and langserve re-checks — get dramatically faster; the compiler test suite's checker file alone dropped from 590s+ to 40s.
