- **Fix: fleet gateway pods crashlooped when the app's jac.toml carried `[scale.microservices] enabled = false`**: the unified k8s target deploys such apps as a `__gateway__` + main fleet anyway, but `jac scale gateway` refused to start inside the pod ("Microservice mode is disabled"), exiting 1 on every restart. The opt-out governs whether the current process realizes a fleet - a local `jac start`/`jac scale` still honors it, including apps that declare routes but opt out to run single-process - never whether a member of an already-realized fleet may serve: the gateway action now defers to `JAC_SV_SIBLING=1`, the signal every fleet pod's command exports and the one service pods already honor. The key is also **deprecated**: declaring `[scale.microservices.routes]` is what turns microservice mode on, a one-time warning now points at the migration (delete the key; remove the routes table to run single-process), and a future release removes it.
