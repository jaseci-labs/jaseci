The compiler front end moves to a flat syntax arena: the parser emits the concrete syntax tree as index-linked integer pools (a value) instead of a mutable object graph, with one materialization bridge rebuilding unitree nodes per parse. The parser now compiles fully natively (zero seam demotions) and ships as a sealed artifact alongside the lexer; full compiles ride it at 1.5-1.9x over the bytecode path. New zero-marshal syntax diagnostics: `jac check --parse_only` is truly syntax-only and the language server publishes parse errors immediately on change, 13-16x faster than a full parse. A new `jac gen-unitree` generator derives the arena builder surface from the unitree constructors with `--verify` as the CI drift gate. Native backend fixes along the way: Mach-O inline relocation addends, zerofill/common-symbol merging, optional-list `extend`, multi-member union lowering, and runtime `.value`/`.name` on string-valued enums.
