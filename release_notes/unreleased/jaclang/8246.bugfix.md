- **byLLM: finish_tool argument robustness**: a `by llm()` call with tools no longer crashes with a raw `TypeError` when the model misnames the `finish_tool` argument; misnamed or flattened payloads that validate against the declared output type are accepted, and unusable arguments are fed back as a recoverable tool error the model can retry.
- **byLLM: json_object-downgrading backends accept typed requests**: the schema hint injected into `response_format` requests now states "Respond with a single JSON object", so backends that silently downgrade `json_schema` to `json_object` (which requires the word "json" in the prompt) no longer reject every zero-tool typed `by llm()` call outright.
