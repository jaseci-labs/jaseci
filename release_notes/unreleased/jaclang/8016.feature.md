- **Feature: GraphMend graph-break elimination, on by default for torch code**: GraphMend rewrites, at compile time, the PyTorch 2 FX graph breaks that make TorchDynamo fall back to eager execution, so the forward pass stays a single contiguous FX graph. It detects fixable break patterns under `torch.compile` entry points (decorated functions and classes, or call-site wraps like `torch.compile(Model())`) in `.jac` and plain `.py` source alike, and applies three transforms: data-dependent validation guards lower to graph-native `torch._assert_async` with the original exception restored at an eager boundary (trap), data-dependent `if`/`else` branches are predicated into `torch.where` selections (where), and side-effecting `print` and logger calls are buffered and replayed in program order after the graph runs (defer). GraphMend is on by default in `auto` mode: it engages per compiled module exactly for modules that import `torch` or a `torch.*` submodule, detected syntactically, so every other module compiles byte-identically to before. GraphMend-active compiles stay cached, with the GraphMend configuration folded into the cache key so configuration changes invalidate instead of colliding.
- **Feature: GraphMend configuration**: `[run] graphmend = "auto" | "on" | "off"` in `jac.toml` (default `auto`; booleans valid) controls the mode, mirrored by `CompileOptions(graphmend=...)`; there is no CLI enable flag, and `false`/`"off"` is the kill switch. `--graphmend-disable` / `run.graphmend_disable` skips individual transforms (`trap`, `where`, `defer`).
- **Feature: GraphMend claims imported model code automatically**: there is no module scope to configure. A module claims itself when it imports torch and either wraps something with `torch.compile` or defines a `forward` whose class binds a torch Module base; claiming then follows that module's eager imports transitively, so a library module reached only through its importer is transformed too. The closure stops at `if TYPE_CHECKING:` imports, at the top-level package of the module that seeded it, and at `torch`, `jaclang` and the standard library. Claimed `.py` modules are routed through GraphMend by the meta importer and by a `SourceFileLoader` hook, installed only once torch enters the process so a run without torch leaves the import machinery untouched; a module the compiler cannot handle falls back to its original source rather than breaking the import.
