- **New lint rule `remove-redundant-semi` (W3013)**: `jac fmt --lintfix` now removes every standalone no-op semicolon from every statement body, so `{;}`-style blocks collapse to `{}`, `x = 1;;` loses its surplus semicolon, and lone `;` lines between statements are deleted. This applies to ability and function bodies, control-flow blocks (`if`/`else`, `while`, `for`, `try`/`except`/`finally`), `test` blocks, entry blocks, `impl` bodies and lambdas. A `match`/`switch` case body cannot be empty, so a lone case-body semicolon is kept and only surplus ones are removed. The rule subsumes the old `remove-import-semi` (W3011); that name is kept as an alias so existing `[check.lint]` selects keep working.
- **Empty code blocks format as `{}`**: the formatter previously rendered an empty code block as `{ }` (with an inner space) while an empty archetype body rendered `{}`. All empty blocks now render `{}`.
