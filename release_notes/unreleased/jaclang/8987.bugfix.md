- **Fix: the checker, importer, parser and store findings from validating workspace apps (#8982)**: a compile error in a shared `impl/foo.impl.jac` annex no longer surfaces as a bare `No bytecode found` (the annex predicate learns the shared-folder layout, and the diagnostic ledger's `owned_errors` is the one module-scoping rule the compiler's failure retention and the importer both use); a compiler module is built on the bootstrap tier whenever a schedule dependency is mid-import, whichever import reached it first, so cold-start `symbol_utils` re-entry cannot recur, the loaders' pre-imports are declared data (`IR_SCHED_DEPS` and friends), and a silent no-bytecode failure names the dependency in flight; a duplicate diagnostic code is caught by a source scan in the registry test and by CI's contribution checks before any kit build; a comprehension iterable is any operator expression short of the ternary (`[len(r) for r in [h] + rows]`, `", ".join(str(e) for e in a + b)`); after a dot every keyword is an attribute, so `sys.exit(0)` parses unescaped; the lexer's keyword table is the one source of reserved words (the parser and the grammar extractor derive from it, `own`/`mut`/`imm`/`awaiting` now get E0013 instead of an E0004 cascade, E0013's help names the backtick escape, and Foundation > Keywords prints the complete list, pinned by a test); destructuring over an explicit `any` iterable binds `any` rather than Unknown; overload selection honours a declared `self` type against the receiver, so `text.split(...)` on a `str` returns `list[str]`, and an annotated `list[str]` local keeps its annotation; a bridged stub that returns a sync generator is typed as the coroutine it is; and `PgStore.ensure_schema_once` readies the store before taking the schema gate instead of deadlocking on a store nobody has readied.
